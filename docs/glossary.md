# 名詞表

人物、地點與重要物品另有專頁，可從左側導覽進入。這裡收錄其他常出現的名詞。

## 世界與勢力

| 名詞 | 說明 |
| --- | --- |
| 伴陽 | 至高監督者以契約換來、高懸於艾爾托瑞爾上空的太陽；城市墜入阿弗納斯後變成黑色球體，不時放出落雷 |
| 扎瑞爾 | 曾帶領地獄騎士攻入阿弗納斯的天使，戰敗後成為阿弗納斯之主 |
| 至高監督者 | 艾爾托瑞爾的統治者塔維斯・克雷格，與扎瑞爾簽下契約 |
| 艾爾托瑞爾／艾爾圖加德 | 墜入阿弗納斯的城市／其所屬的國家，見[艾爾托瑞爾](places/艾爾托瑞爾.md) |
| 地獄騎士 | 艾爾托瑞爾的騎士團，源自跟隨扎瑞爾攻入阿弗納斯後撤回的騎士 |
| 托姆 | 勇氣與犧牲之神，艾爾托瑞爾人普遍信仰的神祇 |
| 九獄／阿弗納斯 | 魔鬼居住的地獄；阿弗納斯是九獄的第一層 |
| 冥河 | 流經阿弗納斯的河，艾爾托瑞爾被鐵鍊吊在它的上方 |
| 流浪市集 | 阿弗納斯四處移動的黑市，以靈魂幣交易武器、物資和奴隸 |
| 靈魂幣 | 阿弗納斯通行的貨幣 |
| 鐵手會 | 信仰提爾、托姆與海姆、公開行動的除惡組織 |
| 托姆之臂／托姆之刃 | 連接艾爾托瑞爾南北兩半的兩座橋，托姆之刃刻有能消滅魔鬼的聖符 |
| 英雄之柱 | 大墓地教堂門廊上刻著歷代英雄的柱子，喊出英雄的名字即可啟動 |
| 湧血城寨 | 露露所說扎瑞爾之劍的所在地，被血紅色的物體包圍 |
| 地獄戰爭機器 | 像巨大鎧甲拼裝而成、底下裝著車輪的戰車，以靈魂幣為燃料，也可改裝成燒穢液 |
| 穢液 | 惡魔的血液，抹在武器上會讓目標產生詭異的變異 |
| 煉獄飛昇 | 馬哈迪在流浪市集經營的餐飲與水療店，消費須簽煉獄語契約 |
| 鬼哭神嚎 | 流浪市集裡又髒又吵的酒館，貼著軍閥的懸賞 |
| 伊爾馬特 | 凱侖信仰的神，「讓人從苦難中找到意義的神」 |
| 蘭森德 | 晨曦之主，詹德的信仰；曾派扎瑞爾守護艾德爾格蘭 |
| 巴哈姆特 | 善龍之神 |
| 提亞瑪特 | 龍的神祇，信徒包括白龍魔與阿克漢；被阿斯莫蒂斯打敗、囚禁在阿弗納斯 |
| 阿斯莫蒂斯 | 九獄之主 |
| 滅魔之地 | 露露想起的「惡魔被消滅的地方」，拉爾沙拉在這裡等待隊伍 |
| 懦夫之路 | 哈羅曼之丘的山路；哈魯曼把當年從傳送門逃走的地獄騎士釘在路旁的鐵樹上 |
| 八環議會 | 大法師摩登肯領導的冒險者組織 |
| 羅剎之歌 | 奎恩與馬哈迪的契約化成的樂譜；對一個人唱完，聽者的靈魂就歸阿斯莫蒂斯所有 |

## 魔鬼、惡魔與怪物

| 名詞 | 說明 |
| --- | --- |
| 鬚魔 | 揮長柄大刀、用鬍鬚攻擊的魔鬼，對非魔法武器有抗性 |
| 棘魔 | 形似刺蝟的小型魔鬼 |
| 魅魔 | 能變形成他人模樣的有翼邪魔 |
| 布雷祖魔 | 公羊腿、帶鋼刺長尾、頭上布滿眼睛的惡魔，渾身散發惡臭 |
| 白龍魔 | 侍奉提亞瑪特的魔鬼 |
| 夢魘 | 鬃毛與尾巴燃燒著火焰的惡魔馬，強大邪魔的坐騎 |
| 麥哲羅斯魔 | 六肢、象牙色甲殼、手持三叉戟的人形昆蟲邪魔 |
| 雀魔 | 力量最弱的小型惡魔，會噴出惡臭的毒氣 |
| 夸賽魔 | 能隱形、變形的小型惡魔 |
| 食屍鬼／妖鬼 | 啃食屍體的不死生物 |
| 幽靈／幽影 | 無形的不死生物 |
| 佛洛摩 | 鳥頭、有翼的惡魔，會用震懾尖嘯與劇毒孢子攻擊；阿弗就是一隻佛洛摩 |
| 奈祖貢 | 騎夢魘的魔鬼騎士，例如哈魯曼 |
| 地獄黃蜂 | 有手、能拿長劍的大型黃蜂，毒針可造成麻痺，免疫火焰 |
| 鳥人 | 烏鴉頭的類人生物，聲音被奪走，只能模仿別人說話 |
| 紅帽子 | 由殺戮的恨意所生，帽子必須每三天浸一次鮮血 |
| 鬼婆 | 熬藥、詛咒他人的老婦人形邪惡存在，例如指節骨要塞的主人與古吉林的黃鷺鷥 |
| 羅剎 | 虎頭人形的邪魔，擅長把真身藏在人類外表下 |
| 鏈魔 | 全身纏著鎖鏈的魔鬼 |
| 深獄煉魔 | 強大的高階魔鬼，例如貝爾；加格斯的真身也是深獄煉魔 |
| 角魔 | 有角的魔鬼，例如被扎瑞爾拔掉翅膀的苦痛之息 |
| 尤格洛斯魔 | 據說受阿斯莫蒂斯委託而創造的邪魔，只有真名能真正消滅它們 |
| 安阻膜 | 肥胖的魔鬼；流浪市集的郵局「從這裡到阿弗納斯」由一隻安阻膜經營 |
| 大哥布林 | 騎著雙輪地獄戰車的暴走族 |
| 骨螺 | 背上黏著骷髏、用觸手黏人的怪物，死前會尖叫引來同伴 |
| 地獄獵犬 | 狼一般大、黑毛裡透著火光、會噴火的獵犬 |
| 死亡騎士 | 被喚醒成不死生物的騎士，例如奧蘭蘇斯 |
| 蚊蝠 | 吸血的小型飛行怪物，會在廢墟的管道裡築巢 |
| 至高天巨人 | 來自天界的巨人，例如烏爾德拉克 |
| 豺狼人 | 惡魔領主耶諾谷的手下 |
