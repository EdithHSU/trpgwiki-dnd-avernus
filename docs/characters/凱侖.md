# 凱侖

!!! info ""
    伊爾馬特的牧師，持有[加格斯之盾](../items/加格斯之盾.md)。

## 身分

凱侖對伊爾馬特的信仰堅定，雖然一直懷疑盾中的邪惡力量，仍決定在找到能妥善處理它的人之前自己保管。他可以藉著盾牌施放火球術，也常用驅散不死、聖火術等神術對付不死生物。

## 經歷

- [造訪萬瑟姆普宅](../episodes/2025-04-12.md)：懷疑[奎恩](奎恩.md)弟弟的動搖只是話術，不輕易信任。
- [要進入第二章囉](../episodes/2025-06-14.md)：成為伏擊者的頭號目標，藉盾牌施放火球；戰後以偵測思想審問俘虜，問出敵人是為盾牌而來。
- [半獸人小不點](../episodes/2025-06-28.md)：擋下對至高監督者的處決，主張交由人民審判，並負責移送；拒絕把盾牌交給[希爾維亞](../npcs/希爾維亞.md)研究，也當面拒絕了加格斯的示好。
- [燒焦的魅魔倒下，但他還是很帥](../episodes/2025-08-16.md)：聽到鐵手會據點裡的求救聲；識破假管家後揮錘攻擊，以月華之光逼出魅魔原形，再以死者交談審問屍體。

- [地獄市集逛大街](../episodes/2025-11-22.md)：拒絕簽下煉獄飛昇的消費契約，察覺店員在隱瞞什麼。
