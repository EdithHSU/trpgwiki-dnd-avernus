# 奎恩

!!! info ""
    人類吟遊詩人（低語學院），巴爾之子。

## 身分

奎恩常以音樂、激勵與幻術支援隊友，也擅長假扮他人。他在[燭堡](../places/燭堡.md)打聽過死亡三神的資料。隊伍在對付[萬瑟姆普家族](../npcs/萬瑟姆普家族.md)時，俘虜了他的親弟弟。

## 出身

奎恩原是博德之門貴族家族的繼承人，生來容貌異常美麗。家族因內奸背叛遭到襲擊，弟弟在混亂中被綁走，奎恩僥倖逃脫，被馬戲團的小丑大叔收養。他學會了表演與偽裝，把小丑面具變成武器，用歡笑掩飾痛苦，希望靠名聲讓弟弟找到他。

多年後他終於找到弟弟，對方卻已成了邪教徒。之後奎恩得知自己是巴爾之子、謀殺三神之一的後裔，憤怒、恐懼又自我厭惡；他的笑容變得詭異，甚至開始覺得自己的影子有時慢他一拍。他想要成名，無論付出什麼代價。

## 性格與成長

- 團裡的喜劇擔當，也是最擅長交涉與說謊的人：惡搞俘虜、假扮萬瑟姆普家的人、代表隊伍和殘忍的阿克漢交涉。（[大兒子裸奔](../episodes/2025-04-26.md)、[姆普姆普](../episodes/2025-05-17.md)、[殘忍的阿克漢](../episodes/rec-0038.md)）
- 最重的秘密：獨自和[馬哈迪](../npcs/馬哈迪.md)簽約，死後靈魂歸阿斯莫蒂斯，換弟弟變回普通人；死後的身體則留給[阿弗](../npcs/阿弗.md)，阿弗本人不知道。殺戮之神的兒子，用把自己賣進地獄的方式救家人。（[羅剎之歌](../episodes/rec-0040.md)）
- 對外人多疑，試探假管家、夜裡跟蹤詹德；對阿弗卻無條件溫柔，是牠最信任的人。（[燒焦的魅魔倒下，但他還是很帥](../episodes/2025-08-16.md)、[學長是個超級吸血鬼是否搞錯了甚麼](../episodes/2025-12-2.md)、[思考魔生的阿弗](../episodes/2025-10-25.md)）
- 缺席了好幾集，一回來就被隱形的魔物抓上高空摔下。（[沸血湖的摩登肯](../episodes/rec-0048.md)）

!!! quote "觀察"
    奎恩為了弟弟而活，所以和馬哈迪的契約不是一時衝動，而是他從小到大唯一的目標。他相信藝術應該反映靈魂、揭示真正的自我，但他最真實的那一面，正是對隊友藏得最深的部分。
