# 奎恩

!!! info ""
    人類吟遊詩人，巴爾之子。

## 身分

奎恩常以音樂、激勵與幻術支援隊友，也擅長假扮他人。他在[燭堡](../places/燭堡.md)打聽過死亡三神的資料。他與親弟弟自幼信奉巴爾，隊伍在對付[萬瑟姆普家族](../npcs/萬瑟姆普家族.md)時俘虜了這個弟弟。

在阿弗納斯，奎恩瞞著同伴與[馬哈迪](../npcs/馬哈迪.md)簽約，以死後的靈魂換取弟弟的新人生。

## 經歷

- [造訪萬瑟姆普宅](../episodes/2025-04-12.md)：感化被俘的親弟弟，讓他動搖了對巴爾的信仰，並為他安排改信儀式。
- [大兒子裸奔](../episodes/2025-04-26.md)：替萬瑟姆普家的大少爺畫上紅鼻子，以暗示術讓他當眾裸奔到廣場。
- [姆普姆普](../episodes/2025-05-17.md)：穿上敵人留下的衣物假扮萬瑟姆普家的人，一路唬弄地下的惡魔守衛與小惡魔。
- [要進入第二章囉](../episodes/2025-06-14.md)：戰鬥中以鏡影術自保；贊成釋放俘虜。
- [半獸人小不點](../episodes/2025-06-28.md)：在[燭堡](../places/燭堡.md)的酒館結識半獸人學者小不點，打聽死亡三神的書籍。
- [第一屆美鬚大賽](../episodes/2025-07-26.md)：在托姆之刃上用幻影把魔鬼引到橋中央，再衝進敵陣施放雷鳴波。
- [燒焦的魅魔倒下，但他還是很帥](../episodes/2025-08-16.md)：一直試探可疑的管家阿福；易容成魅魔協助審問屍體；在祭壇前以音樂幫蓋比祈禱，並發現附近的秘門。
- [吾劍承忠誠之誓，必逐長夜之影](../episodes/2025-08-30.md)：找到祭壇鐵手中的暗門；站上洗禮盆，向倖存者宣揚[維提克](維提克.md)是受托姆指引拔出聖劍的人。
- [磨人的夸賽魔，看你往哪跑](../episodes/2025-09-14.md)：讓維提克變得巨大堵住傳送門；用隱形術與[蓋比](蓋比.md)回至高大廳找弗莉亞。
- [思考魔生的阿弗](../episodes/2025-10-25.md)：成為[阿弗](../npcs/阿弗.md)最信任的人；對露露施放變巨術。
- [跟錢婆婆交車然後開地獄車車](../episodes/2025-11-15.md)：對「成為惡魔領主」表現出異常的興趣，說自己的目標是繼承父親的家業。
- [地獄市集逛大街](../episodes/2025-11-22.md)：在流浪市集的街頭表演一舉成名；直接問馬哈迪是不是人類。
- [酒館魅魔好難纏](../episodes/2025-11-26.md)：在馬哈迪面前自稱扎瑞爾的朋友，打聽耶諾谷與延長壽命的方法。
- [一見鍾情地獄騎士學長與他的情敵奈祖貢](../episodes/2025-12-1.md)：讓阿弗帶他飛過去，用淬毒的刺劍殺死地獄黃蜂。
- [學長是個超級吸血鬼是否搞錯了甚麼](../episodes/2025-12-2.md)：把自己的表演服給[詹德](../npcs/詹德.md)；夜裡跟蹤詹德、出言試探。
- [滅魔器與獨角獸](../episodes/monkie-2.md)：前一晚拿著靈魂幣盯著獨角獸看；第一個走進單向的拱門，抵達古吉林。

- [殘忍的阿克漢](../episodes/rec-0038.md)：代表隊伍與殘忍的阿克漢交涉。
- [苦痛之息的審判](../episodes/rec-0039.md)：坐在巨人肩上，殺死倒地的大哥布林將軍。

- [貝爾的委託](../episodes/rec-0041.md)：把[阿弗](../npcs/阿弗.md)變成超巨型；主張乾脆放出加格斯。
- [沸血湖的摩登肯](../episodes/rec-0048.md)：重新歸隊，卻被隱形的魔物抓上高空丟下，由[維提克](維提克.md)救起。
- [地獄騎士之墓](../episodes/monkie-3.md)：把[阿弗](../npcs/阿弗.md)變成巨型；被地獄火球打倒。

- [湧血城寨的聖門](../episodes/rec-0050.md)：施放羽落術讓隊友跳下懸崖；留在聖門外照顧阿弗。
