# 維提克

!!! info ""
    [艾爾托瑞爾](../places/艾爾托瑞爾.md)出身的地獄騎士，戰士（戰法師）兼托姆的戰爭牧師。持有[無名屠龍者的聖劍](../items/無名屠龍者的聖劍.md)，之後拔出[扎瑞爾之劍](../items/扎瑞爾之劍.md)，化為天使。

## 身分

維提克是土生土長的艾爾托瑞爾人，在[至高大廳](../places/至高大廳.md)工作，上司是祭司[吉迪恩・萊特沃德](../npcs/吉迪恩・萊特沃德.md)。家住靠近至高大廳的上層區，家中有父母與傭人。升上 6 級時，他兼職成為托姆戰爭領域的牧師；這份神力，是他見證[至高監督者](../npcs/至高監督者.md)墮落之後，持續向托姆祈禱而得到的。

## 出身

維提克是艾爾圖加德小貴族科索格里夫家的次子，父親與精靈情人所生的孩子，仍在家中受到良好的教育。他憧憬身為繼承人的兄長赫茲麥爾，跟著加入了地獄騎士。第一次隨兄長出任務，隊伍就全軍覆沒，維提克是唯一的倖存者，也因此成了繼承人。他認為兄長的死，是自己面對邪惡時的懦弱與自私造成的，從此更嚴苛地鞭策自己。他的坐騎是戰馬奎米爾。

## 性格與成長

- 從正直、火爆的騎士，成了倖存者的象徵：聖劍、誓言、托姆之盔，以及拯救同伴的恩賜。（[半獸人小不點](../episodes/2025-06-28.md)、[吾劍承忠誠之誓，必逐長夜之影](../episodes/2025-08-30.md)）
- 不知不覺轉為邪惡後，說話變得冷酷。被[凱侖](凱侖.md)點破後，他去問[詹德](../npcs/詹德.md)自己是不是真的變了，詹德反而把「若我背離地獄騎士精神就殺了我」的信任交給他；之後他對自己使用托姆的恩賜，向凱侖道歉。（[奧術魔的煩惱](../episodes/rec-0042.md)、[九根權杖](../episodes/rec-0045.md)、[伊爾馬特的紅繩](../episodes/rec-0047.md)）
- 不背棄同袍：獻血救詹德、救起墜地的[奎恩](奎恩.md)；也會出手管人，賞了[安格](安格.md)一巴掌。（[學長是個超級吸血鬼是否搞錯了甚麼](../episodes/2025-12-2.md)、[沸血湖的魔鄧肯](../episodes/rec-0048.md)、[露露的回憶：艾德爾格蘭](../episodes/rec-0051.md)）
- 選擇拔出扎瑞爾之劍，接受自己將不再是原本的自己；臨行前託歐蓓向父母道謝與道歉，請隊友轉告雷亞，這一切都是為了地獄騎士的使命。（[維提克之劍](../episodes/rec-0052.md)）
- 家人至今下落不明；地獄騎士之墓的骨灰堂裡，有他熟悉的家徽。（[地獄騎士之墓](../episodes/monkie-3.md)）

!!! quote "觀察"
    維提克一直把兄長的死歸咎於自己面對邪惡時的懦弱，心底其實也畏懼著邪惡。這解釋了他為什麼對自己的墮落反應這麼激烈：被凱侖點破之後，他沒有辯解，而是去問詹德自己是不是真的變了，最後選擇對自己使用托姆的恩賜。
