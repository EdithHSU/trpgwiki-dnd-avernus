# 維提克

!!! info ""
    [艾爾托瑞爾](../places/艾爾托瑞爾.md)出身的地獄騎士，戰士（戰法師），有精靈血統。持有[無名屠龍者的聖劍](../items/無名屠龍者的聖劍.md)。

## 身分

維提克是土生土長的艾爾托瑞爾人，在[至高大廳](../places/至高大廳.md)工作，上司是祭司[吉迪恩・萊特沃德](../npcs/吉迪恩・萊特沃德.md)。家住靠近至高大廳的上層區，家中有父母與傭人，哥哥很早就過世了。升上 6 級時，他兼職成為托姆戰爭領域的牧師；這份神力，是他見證[至高監督者](../npcs/至高監督者.md)墮落之後，持續向托姆祈禱而得到的。

在阿弗納斯的一次長休後，維提克的陣營轉為邪惡，但他本人還沒有察覺。
