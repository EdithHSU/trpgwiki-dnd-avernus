# 蓋比

!!! info ""
    提夫林遊俠，鐵手會的斥候。懂煉獄語，具「怪物殺手」特性。原本信仰賽倫涅，在[至高大廳](../places/至高大廳.md)改信托姆。

## 身分

蓋比擅長弓箭，遇到敵人時可以直接得知對方的抗性與弱點。為了對付魔鬼對非魔法武器的抗性，隊伍替蓋比的箭矢鍍了銀，[哈金娜](../npcs/哈金娜.md)也分了銀箭給她。她可以接受像[阿弗](../npcs/阿弗.md)那樣願意合作的魔物，但明擺著作惡的絕不放過。

## 出身

蓋比 11 歲時，博德之門郊外的提夫林聚落發生了一場小型的惡魔召喚儀式，村民被屠殺殆盡；趕來的**鐵手會**殲滅了惡魔，只找到她一個倖存者。傷癒後她要求加入鐵手會，指揮官以為她只是一時衝動而拒絕，直到她捧著自己割下的雙角跪在他面前起誓，要用餘生對抗邪惡，才被收入麾下。

平時她能得體地應對，但一遇到剷除邪惡、尤其是惡魔的事，就會變得過度積極、失去分寸，讓指揮官很擔心。她總是披著斗篷、拉上兜帽遮住提夫林的身分，只在野外或熟識的鐵手會成員面前露出本來的面貌。

## 性格與成長

- 身世解釋了她的一切：村莊毀於惡魔召喚儀式，被鐵手會收留，從此把鐵手會的人當成家人。（[羅剎之歌](../episodes/rec-0040.md)）
- 所以她最恨魔鬼、改信托姆，也會對隊上的邪惡存在爆發：射向苦痛之息的箭被安格擋下，最後親手處決了對方。（[燒焦的魅魔倒下，但他還是很帥](../episodes/2025-08-16.md)、[苦痛之息的審判](../episodes/rec-0039.md)）
- 說到做到：遵守承諾放走鼠人芬尼克，也免掉了[奎恩](奎恩.md)欠她的錢。（[地獄市集逛大街](../episodes/2025-11-22.md)、[沸血湖的魔鄧肯](../episodes/rec-0048.md)）
- 動機最清楚：要救出被困在扎瑞爾飛行堡壘裡的鐵手會隊長。衝過火牆救平民時，團員說很像她村莊被毀的那天。（[貝爾的委託](../episodes/rec-0041.md)、[湧血城寨的聖門](../episodes/rec-0050.md)）

!!! quote "觀察"
    蓋比相信該懲罰的是邪惡的行為，而不是邪惡的思想，不能讓仇恨蒙蔽雙眼而傷害別人；可是一遇到惡魔，她又很難保持冷靜。她一直在這兩者之間拉扯：處決已經投降的苦痛之息之前，她先讓凱侖占卜過。
