# 蓋比

!!! info ""
    提夫林遊俠，懂煉獄語，具「怪物殺手」特性。不喜歡魔鬼。原本信仰賽倫涅，在[至高大廳](../places/至高大廳.md)改信托姆。

## 身分

蓋比擅長弓箭，遇到敵人時可以直接得知對方的抗性與弱點。為了對付魔鬼對非魔法武器的抗性，隊伍替蓋比的箭矢鍍了銀，[哈吉娜](../npcs/哈吉娜.md)也分了銀箭給蓋比。

蓋比小時候的村莊因為一場惡魔召喚儀式而毀滅，趕來處理的**鐵手會**收留了蓋比，從此蓋比把鐵手會的人當成家人。蓋比可以接受像[阿弗](../npcs/阿弗.md)那樣願意合作的魔物，但明擺著作惡的絕不放過。蓋比曾在長休後轉為邪惡，之後又回到了善良。
