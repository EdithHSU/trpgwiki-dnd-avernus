# 歐蓓

!!! info ""
    卓爾法師，混亂善良。是[露露](../npcs/露露.md)最常說話的對象。

## 身分

害羞的[露露](../npcs/露露.md)第一次見面就選了歐蓓當溝通窗口，之後露露也常以心靈感應跟她說話、陪在她身邊。

## 經歷

- [造訪萬瑟姆普宅](../episodes/2025-04-12.md)：協助[奎恩](奎恩.md)感化他被俘的弟弟。
- [要進入第二章囉](../episodes/2025-06-14.md)：基於混亂善良的傾向，主張釋放俘虜。
- [歡迎來到埃爾圖迦德](../episodes/2025-07-12.md)：被露露選為溝通對象，施展通曉語言聽懂天界語；擔心阿弗納斯的光照對卓爾不利。
- [第一屆美鬚大賽](../episodes/2025-07-26.md)：看到有人被追殺立刻出手；用火球術讓學校裡的殭屍安息，並鼓勵露露慢慢找回記憶。
- [燒焦的魅魔倒下，但他還是很帥](../episodes/2025-08-16.md)：以緩慢術壓制布雷祖魔；對管家阿福起疑，以偵測魔法找出變化系靈光。
- [你做了什麼（1）](../episodes/2025-09-07-1.md)：保管從燃燒殭屍身上找到的神秘藥水。
- [磨人的夸賽魔，看你往哪跑](../episodes/2025-09-14.md)：被夸賽魔嚇唬卻沒被嚇到；堅決反對冒險拔下大公的頭盔；施放李歐蒙小屋，並帶著露露探索墓穴。
- [在阿弗納斯行軍然後拿到穢液](../episodes/2025-11-08.md)：目睹[安格](安格.md)用穢液做實驗，勸他這種力量風險太高。
- [地獄市集逛大街](../episodes/2025-11-22.md)：與火蜥兄弟談賣車與改裝，替凱侖的堅持辯護。
- [酒館魅魔好難纏](../episodes/2025-11-26.md)：在酒館提醒被魅魔纏上的安格別喝多了。
- [一見鍾情地獄騎士學長與他的情敵奈祖貢](../episodes/2025-12-1.md)：提議賣掉戰車；能毫無不適地拿起靈魂幣；用任意門帶走[詹德](../npcs/詹德.md)，聽取他的遺言；仍向伊莉絲翠禱告。
- [學長是個超級吸血鬼是否搞錯了甚麼](../episodes/2025-12-2.md)：開導想起扎瑞爾而愧疚的露露。
- [滅魔器與獨角獸](../episodes/monkie-2.md)：調查滅魔器；說出在幽暗地域成長的過去，被[維提克](維提克.md)以托姆的恩賜拉回善良。
- [黃鷺鷥唱歌](../episodes/2026-01.md)：（前情提要）被[維提克](維提克.md)拉回善良。
- [殘忍的阿克漢](../episodes/rec-0038.md)：逐條修改龍語石板契約的條款，第一個簽名；以力場牆推開大哥布林。
