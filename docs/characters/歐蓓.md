# 歐蓓

!!! info ""
    卓爾劍詠法師，伊莉絲翠的信徒。是[露露](../npcs/露露.md)最常說話的對象。

## 身分

害羞的[露露](../npcs/露露.md)第一次見面就選了歐蓓當溝通窗口，之後露露也常以心靈感應跟她說話、陪在她身邊。

## 出身

歐蓓 96 歲，以精靈來說還未成年，卻已是圖書館「至高之廳」的資深館員。她是卓爾女神伊莉絲翠的虔誠信徒；這位女神近百年來無法授予神力，所以她沒有成為牧師，而是在其他神職人員的教導下走上學者的路。

她相信權貴與平民的差距應該被弭平，曾替革命者在迷宮般的圖書館裡找文獻；革命失敗後，她成了下一個被盯上的目標。

## 性格與成長

- 在幽暗地域長大，因為遇到伊莉絲翠的追隨者而改變，相信邪魔也有向善的可能。（[滅魔器與獨角獸](../episodes/monkie-2.md)、[羅剎之歌](../episodes/rec-0040.md)）
- 隊伍的接點：凱侖告解的對象、露露傾訴的對象，也陪[蓋比](蓋比.md)談身世、開導安格的小魔鬼，並促成加格斯的事向全隊公開。（[貝爾的委託](../episodes/rec-0041.md)、[羅剎之歌](../episodes/rec-0040.md)、[血痂裡的城寨](../episodes/rec-0049.md)）
- 對[安格](安格.md)最有耐心，勸他別亂用穢液；攻擊因猶豫而落空後，仍選擇用安格聽得進去的方式勸他。（[艦橋上的冥想](../episodes/rec-0044.md)、[露露的回憶：艾德爾格蘭](../episodes/rec-0051.md)）
- 自己也滑向過邪惡，由[維提克](維提克.md)以聖劍誓詞拉回。（[地獄市集逛大街](../episodes/2025-11-22.md)、[滅魔器與獨角獸](../episodes/monkie-2.md)）

!!! quote "觀察"
    歐蓓習慣在下判斷之前先聽各方的意見，也相信美麗的事物能引人超越自我、走向真理，這正是她在隊上當調停者的原因。她對自稱同道的人容易全心信任，這份虔誠有時也會讓她看不清對方。
