# 安格

!!! info ""
    人類遊俠（幽域追蹤者），以弓箭作戰。與小魔鬼**塔吉恩**簽了契約。

## 身分

塔吉恩先前在萬瑟姆普宅被隊伍綁住後逃走，得知萬瑟姆普家族垮台後主動找上安格，想簽約合作。安格設了試用期，並要求牠平時只能以動物形態出現。小魔鬼平時以動物形態跟隨，能替安格偵察，但遇到神聖的力量就會嚇得躲起來。

## 出身

安格生於費倫北方一個政局動盪的獵人部落。在一次部落試驗中，他被陷害成殺害族人的兇手，遭到通緝，被迫逃離家園，長年躲在險峻的幽暗地域，避開擅長追蹤的族人。

為了查出當年陷害他的真相，他來到博德之門，成為[萬瑟姆普家族](../npcs/萬瑟姆普家族.md)雇用的傭兵，一邊執行任務、一邊在權貴之間打探情報，想拼湊出統治部落的激進政權背後的陰謀與主使。他相信自由得靠力量去爭取與捍衛。

## 性格與成長

- 往暗處走得最遠：與小魔鬼簽約、用惡魔穢液做活體實驗，再到接受加格斯給的配方。（[要進入第二章囉](../episodes/2025-06-14.md)、[滅魔器與獨角獸](../episodes/monkie-2.md)、[伊爾馬特的紅繩](../episodes/rec-0047.md)）
- 反問「善良在這裡是必要的嗎」，暫時拒絕托姆的恩賜；用風牆術殺死被詛咒的守衛，挨了一巴掌、引來露露之怒，仍堅持效率至上。（[九根權杖](../episodes/rec-0045.md)、[露露的回憶：艾德爾格蘭](../episodes/rec-0051.md)）
- 對自己人講義氣：答應把靈魂幣分給小魔鬼、揚言保護牠；也對[歐蓓](歐蓓.md)坦承控制不了穢液，答應以後先說一聲。（[艦橋上的冥想](../episodes/rec-0044.md)、[血痂裡的城寨](../episodes/rec-0049.md)）
- 被蒙在鼓裡的事最多：小魔鬼拜加格斯為師、學吞噬靈魂時，他並不知情。（[奧蘭蘇斯的日記](../episodes/monkie-4.md)）

!!! quote "觀察"
    被誣陷、被追殺的過去，讓安格習慣只相信自己的直覺和經驗，而不依賴別人的承諾；追查真相時，他也常忽略眼前的善意，甚至懷疑想幫他的人。他拒絕托姆的恩賜、不服維提克的責備，都和這一點吻合。

## 陣營軌跡

中立 → 邪惡（[在阿弗納斯行軍然後拿到穢液](../episodes/2025-11-08.md)長休後暫時轉為邪惡；最晚在[滅魔器與獨角獸](../episodes/monkie-2.md)已是邪惡）→ 暫時拒絕托姆的恩賜（[九根權杖](../episodes/rec-0045.md)）
