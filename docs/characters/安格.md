# 安格

!!! info ""
    人類遊俠，以弓箭作戰。與一隻小惡魔簽了契約。

## 身分

這隻小惡魔先前在萬瑟姆普宅被隊伍綁住後逃走，得知萬瑟姆普家族垮台後主動找上安格，想簽約合作。安格設了試用期，並要求牠平時只能以動物形態出現。小惡魔平時以動物形態跟隨，能替安格偵察，但遇到神聖的力量就會嚇得躲起來。
