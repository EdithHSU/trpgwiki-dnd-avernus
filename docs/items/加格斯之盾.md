# 加格斯之盾

!!! info ""
    又稱「隱藏領主之盾」。盾中封印著自稱「隱藏領主」的魔鬼加格斯，目前由[凱侖](../characters/凱侖.md)持有。

## 能力

盾中的加格斯會說話，聲音低沉濕滑。持盾者可以喚出加格斯，讓盾牌施放火球術。

## 來歷

盾牌由博德之門一個在多座城市都有勢力的貴族家族保管多年。據[希爾維亞](../npcs/希爾維亞.md)所說，加格斯是被派來腐化凡人的魔鬼，已藉由腐化凡人成長為近乎半神的存在；博德之門近來的腐敗，可能與這面盾影響周遭有關。加格斯的真身是一隻**深獄煉魔**，靈魂與身體都被關在盾裡。[月色](../npcs/月色.md)說，這面盾曾經是天界的東西，但上面的圖案已經被扭曲，現在是一張魔鬼的臉。

加格斯想拿回原本的身體與力量，一路上同時接觸了凱侖、安格和安格的小惡魔。凱侖已向全隊公開，並承諾：若加格斯真的幫忙拯救艾爾托瑞爾，就想辦法幫他。
