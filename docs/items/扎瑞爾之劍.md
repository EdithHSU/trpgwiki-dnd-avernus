# 扎瑞爾之劍

!!! info ""
    扎瑞爾戰敗前託付給[露露](../npcs/露露.md)藏起來的劍。保留了扎瑞爾的善良力量，露露相信它能喚起扎瑞爾的良知。與維提克的[無名屠龍者的聖劍](無名屠龍者的聖劍.md)是不同的兩把劍。如今由[維提克](../characters/維提克.md)拔出，自稱「維提克之劍」。

## 來歷

扎瑞爾被俘之前，吩咐露露把她的劍藏起來，以免落入魔鬼手中。扎瑞爾最忠誠的地獄騎士**[耶爾](../npcs/耶爾.md)**帶著劍逃跑，將劍插入石頭，露露以靈魂中的每一分力量在劍周圍升起護盾，建立了保護這把劍的堡壘。之後露露失去了大部分記憶，忘了劍藏在哪裡。

露露後來說，劍在一座被血紅色物體包圍的**[湧血城寨](../places/湧血城寨.md)**；惡魔領主[耶諾古](../npcs/耶諾古.md)一直想摧毀它。[奧蘭蘇斯](../npcs/奧蘭蘇斯.md)的日記揭露，幫露露藏劍的是將軍[耶爾](../npcs/耶爾.md)。隊伍最後在湧血城寨大教堂的聖座上，看到這把插在石中的劍。

## 維提克之劍

劍旁的天界語碑文寫著：與此劍合而為一的人，其存在也將消失。拔劍的人會轉化為天使，陣營變為守序善良，性格也隨之改變。[維提克](../characters/維提克.md)決定由自己來拔，劍掙扎著想脫手，最後被他制服；他化為有一對羽翼的天使。劍是有智能的武器，以少年般的嗓音說：從今以後，它就是**維提克之劍**。
