# 無名屠龍者的聖劍

!!! info ""
    傳說中斬殺紅龍的無名女子所用的巨劍，安葬在[至高大廳](../places/至高大廳.md)大教堂的地下。現由[維提克](../characters/維提克.md)持有。

## 傳說

伴陽出現前的某一年，一條年輕的紅龍讓艾爾托瑞爾民不聊生。一名衣著破舊、沒有穿盔甲的女子舉著巨劍衝向紅龍，把牠斬殺。居民激動地上前想感謝她時，她已經死了。這名無名女子被安葬在大教堂，遺體至今沒有腐朽。有人說她是托姆的化身，也有人說是托姆賜予了她生命。

## 能力

這把巨劍是魔法武器，命中活物時會造成「創傷」，讓目標持續受到光耀傷害。說出命令語時，劍刃會發光。

維提克的命令語是：「**吾劍承忠誠之誓，必逐長夜之影**」。
