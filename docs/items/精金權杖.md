# 精金權杖

!!! info ""
    曾屬於[扎瑞爾](../npcs/扎瑞爾.md)的九根精金權杖，是打開伴陽的鑰匙。[貝爾](../npcs/貝爾.md)想拿它推翻扎瑞爾，委託隊伍找回來，但隊伍決定不交給他。

## 概況

權杖被扎瑞爾的手下藏了起來。依貝爾的[奧術魔](../npcs/奧術魔.md)所說，權杖和**伴陽**「是一套的」，只有像貝爾那樣的魔鬼大公才能使用。伴陽目前還掛在[艾爾托瑞爾](../places/艾爾托瑞爾.md)上空。

死者交談術問出，權杖在[墜毀的飛行堡壘](../places/墜毀的飛行堡壘.md)的**保險櫃**裡。隊伍打開保險櫃，找到九根權杖，以煉獄語刻著「陰謀之陽 1」到「陰謀之陽 9」；這個詞也出現在至高監督者的契約上，指的就是伴陽。隊伍推斷，把權杖插進伴陽上的鎖，就能打開它。[魔鄧肯](../npcs/魔鄧肯.md)說，打開伴陽會解放裡面關著的東西，「大概是某個天界生物」。
