# 托姆之盔

!!! info ""
    托姆賜給艾爾托瑞爾過去一名聖騎士英雄的金色頭盔。目前戴在[雷文加德大公](../npcs/雷文加德大公.md)頭上。

## 傳說

[大墓地](../places/大墓地.md)教堂的彩繪玻璃上，描繪著托姆把這頂金色頭盔戴到一名信奉托姆的聖騎士頭上。傳說頭盔能讓有價值的配戴者與神聖的存在交流。教堂地下有一座同一名英雄的下跪雕像，頭上原本應該戴著這頂頭盔。

## 現況

隊伍找到雷文加德大公時，頭盔就戴在他頭上，正與深淵的力量互相抗衡。隊伍判斷，只要讓頭盔代表的托姆之力回到大墓地地下，就能淨化那裡、關閉深淵傳送門；但若直接拔下頭盔，大公可能會死。
