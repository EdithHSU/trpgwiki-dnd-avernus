# 靈魂幣

!!! info ""
    [阿弗納斯](../places/阿弗納斯.md)通行的貨幣，每一枚都封著一個靈魂。也是地獄戰爭機器的燃料。

## 概況

靈魂幣直徑約 5 英寸、厚 1 英寸，刻有煉獄語。裡面的靈魂，多半是違反與魔鬼的契約、或被鬼婆詛咒的人。拿著靈魂幣的人會感受到裡面靈魂的情緒，帶得越多越容易被淹沒。

地獄戰車以靈魂幣為燃料，一枚可以用 24 小時。投進熔爐後，靈魂會困在爐裡直到能量耗盡，然後**永久毀滅，連神力都無法挽回**。

在阿弗納斯，最搶手的貨物是靈魂：類人生物的靈魂才值錢，越善良越值錢；惡魔的靈魂則很常見、不值錢。
