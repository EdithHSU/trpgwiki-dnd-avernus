# 燭堡

!!! info ""
    矗立於海崖之上、俯瞰大海的古老城堡，以收藏知識聞名。

## 概況

燭堡有灰色的城牆與蒼白的尖塔。進入燭堡必須獻上一本書或卷軸。外圍有宿舍、客房、澡堂、花園與酒館，內堡則是有上百名學者的大圖書館。僧侶身穿紫袍，聖徽是一隻睜開的眼睛，上面有燃燒的蠟燭。

## 相關人物

- [希爾維亞](../npcs/希爾維亞.md)：在燭堡研究魔鬼的提夫林學者。
- 小不點：在燭堡讀書的半獸人，信仰知識之神歐格瑪。
- 福萊斯特：同行到燭堡後留下的學者。
