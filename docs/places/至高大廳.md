# 至高大廳

!!! info ""
    [艾爾托瑞爾](艾爾托瑞爾.md)斷崖上獻給托姆的白色大理石城堡，城市的政治與宗教中心。

## 現況

五座望塔只剩三座，大門被打碎，城堡西側一片瓦礫，但大教堂仍屹立在城堡中央。庭院裡有地獄犬徘徊，外圍的守衛都已經戰死。

- **大教堂**：長廳的柱子被地獄魔法扭曲成扎瑞爾的形象。中央高台上有**托姆的祭壇**，雕著一隻緊握拳頭的鐵手；拉下旁邊的操縱桿，鐵拳會張開，手掌中藏著通往地下的螺旋階梯。帷幕後的側祭壇已被邪魔褻瀆。
- **無名屠龍者的靈柩**：螺旋階梯下方的小室，安葬著屠龍的無名女子，[無名屠龍者的聖劍](../items/無名屠龍者的聖劍.md)原本放在這裡。
- **地下墓穴**：祭司[弗莉亞](../npcs/弗莉亞.md)帶著一百多名倖存者躲在這裡。墓穴裡有托姆議會的會議室、平民與騎士的墓室、存放遺體的地窖、私人儀式用的神殿，以及學者大廳。
