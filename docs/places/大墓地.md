# 大墓地

!!! info ""
    [至高大廳](至高大廳.md)範圍外的墓園，城市墜落後不斷有不死生物湧出。

## 概況

墓碑之間有骷髏和殭屍遊蕩，許多墳墓被挖開，小建築裡的棺材也被打開了。墓園裡有一座教堂：

- **英雄之柱**：教堂的大理石門廊兩旁，立著刻有艾爾托瑞爾歷代英雄的柱子，大聲喊出柱上英雄的名字就能啟動它的力量。
- **彩繪玻璃**：幾乎全被砸碎，只有一扇描繪托姆賜下[托姆之盔](../items/托姆之盔.md)的窗戶整片掉在地上。
- **地下**：處理遺體的工作坊、骨堂、冥想室，以及最深處的淺水池。水池的一面牆被扭曲成**通往深淵的傳送門**，池水被深淵流出的黑色液體汙染。

教堂的祭司是[吉迪恩・萊特沃德](../npcs/吉迪恩・萊特沃德.md)。
