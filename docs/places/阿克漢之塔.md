# 阿克漢之塔

!!! info ""
    提亞瑪特的信徒[殘忍的阿克漢](../npcs/殘忍的阿克漢.md)的據點，接近提亞瑪特的神殿。

## 概況

黑色高塔聳立在地平線上，城牆插滿焦黑骷髏頭的鐵刺，塔尖分成五根像爪子般刺向天空，一條沾滿灰燼的巨龍盤據在塔上；塔內有幾條較小的龍，城牆上巡邏的是腐爛程度不一的不死守衛。

阿克漢平常在山腰的營地進行儀式：營地設在一顆**巨大的龍頭骨**裡，四周散落房屋大小的骨頭，骨頭之間搭著軍用帳篷。被囚禁在阿弗納斯的提亞瑪特，牢籠推測就在這具龍骨深處。
