# 萬瑟姆普宅

!!! info ""
    博德之門[萬瑟姆普家族](../npcs/萬瑟姆普家族.md)的宅邸。地下藏著邪教的據點。

## 地上

依廚房幫傭奧利佛畫的地圖：北側是正門，另有供馬車用的側門；前廳連接廚房與宴會廳，廚房裡有一座小樓梯可以上樓；地下室通往食物儲藏庫。二樓是家族的私人空間，深居簡出的公子瑟斯維爾就住在這裡，平時由僕人把餐點送到房門口。二樓還有一間擺著黃金裝飾品的收藏室。

## 地下

二樓有一道隱藏的石板密門，木梯通往地下：

- **黑曜石祭壇大廳**：祭壇上噴出天使形狀的火焰，帶有扎瑞爾的意象。天花板畫著高位階的惡魔，地板刻著用來占卜、溝通的金色法陣。
- **更衣室與宿舍**：存放教團長袍與金色的惡魔面具，宿舍裡有十張床。
- **私人房間**：掛著描繪靈魂墮化為惡魔的畫，箱子裡放著托姆聖徽造型的護手。
- **後勤區**：廚房、糧倉、酒窖，以及掛著獸屍的冷藏室，補給相當充足。
- **地牢**：由一隻像蛇的獄卒看守，關押著囚犯。
