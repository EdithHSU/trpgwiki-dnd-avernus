# 阿弗納斯

!!! info ""
    九獄的第一層，由[扎瑞爾](../npcs/扎瑞爾.md)統治。艾爾托瑞爾被鐵鍊吊在它的上空，惡魔與魔鬼在這裡不斷交戰。

## 環境

天空昏暗、布滿汙濁的塵雲，不時有流星墜落砸在地上；地平線的另一端不斷閃著光芒，像有九個太陽。這裡沒有天氣、日月或星辰，空氣中瀰漫硫磺與焦油的臭味，灼熱的狂風捲起巨大的沙塵暴，路邊滿是屍塊與蚊蟲。地形不斷變動，沒有人能真正測量兩點之間的距離。

## 阿弗納斯的侵蝕

- **行軍**：在荒地上行走像在狂風吹拂的沙漠中前進，會不斷累積力竭。
- **食物與魔法**：從地表帶來的食物變得毫無味道、甚至有苦味；施法時感覺得到魔網不穩定。
- **陣營**：待得越久，越容易被這裡的邪惡侵蝕，陣營轉為邪惡；待太久就會永久改變。
- **貨幣**：這裡通行的是[靈魂幣](../items/靈魂幣.md)，最搶手的貨物是靈魂。

## 地點

- [指節骨要塞](指節骨要塞.md)：鬼婆瘋喜鵲與鳥人的據點，整備地獄戰爭機器。
- [流浪市集](流浪市集.md)：四處移動的黑市，主人是馬哈迪。
- [哈魯曼之丘](哈魯曼之丘.md)：鐵樹上穿刺著逃避職責的騎士亡魂。
- [骨脊林](骨脊林.md)：預言家鬼婆紅露絲所在的骨之森林。
- [阿克漢之塔](阿克漢之塔.md)：提亞瑪特的信徒阿克漢的據點。
- [貝爾的熔爐](貝爾的熔爐.md)：前任大公貝爾的火山鋼鐵堡壘。
- [墜毀的飛行堡壘](墜毀的飛行堡壘.md)：扎瑞爾過去的飛行堡壘，墜毀在火焰平原上。
- [地獄騎士之墓](地獄騎士之墓.md)：哀悼地獄騎士的墓穴，騎士的靈魂曾被扎瑞爾束縛在這裡。
- [湧血城寨](湧血城寨.md)：被巨大血痂包住的城寨，扎瑞爾之劍就在裡面。
