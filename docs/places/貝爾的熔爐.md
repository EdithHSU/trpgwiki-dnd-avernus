# 貝爾的熔爐

!!! info ""
    [貝爾](../npcs/貝爾.md)在[阿弗納斯](阿弗納斯.md)的據點，蓋在火山坡上的多層鋼鐵堡壘。

## 概況

堡壘全以鋼鐵鑄成，完全不散熱，裝飾只有鐵鏈與尖刺，城牆附近有魔鬼軍隊守衛。城門由角魔與鬚魔把守，隊伍是靠[拉爾薩拉](../npcs/拉爾薩拉.md)的介紹信才得以進入。裡面熱得讓人力竭，穿著厚重盔甲的人更難受。

沿螺旋階梯往下是巨大的**鍛造室**：岩漿流過室內，皮膚如煤炭、頭髮如火焰的巨人戴著鐐銬，打造巨大的武器與盔甲。貝爾坐在飛行王座上監工。

## 經歷

- [苦痛之息的審判](../episodes/rec-0039.md)：籠中的尤格洛斯魔巴茲特說知道熔爐的位置；拉爾薩拉替隊伍指出方向。
- [羅剎之歌](../episodes/rec-0040.md)：隊伍抵達熔爐，見到貝爾，詢問湧血城寨的位置。
- [貝爾的委託](../episodes/rec-0041.md)：隊伍與火巨人工匠交手，通過貝爾的測試。
