# 艾德爾格蘭

!!! info ""
    長年受豺狼人侵擾的小鎮。扎瑞爾還是天使時，曾受洛山達之命守護這裡。隊伍在湧血城寨的聖座前，被帶進了[露露](../npcs/露露.md)關於這座小鎮的回憶。

## 概況

很久以前，一位洛山達的牧師帶領人民向神祈禱，洛山達被鎮民的勇氣感動，派[扎瑞爾](../npcs/扎瑞爾.md)來擊敗豺狼人，鎮民因此在教堂前立起扎瑞爾的雕像。雕像下刻著「扎瑞爾，艾德爾格蘭的守護者」；靠近雕像的一圈範圍會發出神聖白光，邪魔踏進去會被白色火焰灼燒，向它祈禱還能得到洛山達的恩賜。教堂的女祭司**傑莎・明星**，是傳說中那位牧師的後代。幾代之後，惡魔領主[耶諾古](../npcs/耶諾古.md)親自帶著豺狼人與惡魔殺了回來，扎瑞爾趕來支援時，小鎮已幾乎被摧毀。

露露想起，她曾和扎瑞爾在這裡並肩作戰，那時她跟霸王龍一樣大，扎瑞爾騎著她，對抗豺狼人的領主[耶諾古](../npcs/耶諾古.md)。

## 經歷

- [湧血城寨的聖門](../episodes/rec-0050.md)：女騎士的幽影把隊伍帶進露露的回憶；隊伍保護神殿裡的平民。
- [露露的回憶：艾德爾格蘭](../episodes/rec-0051.md)：隊伍在雕像的聖光中迎戰耶諾古的大軍。
- [維提克之劍](../episodes/rec-0052.md)：天使扎瑞爾降臨，與露露把耶諾古趕進傳送門。
