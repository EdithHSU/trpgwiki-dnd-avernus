# 指節骨要塞

!!! info ""
    [阿弗納斯](阿弗納斯.md)中整備、修理地獄戰爭機器的據點，形似一隻手掌趴在地上。主人是一名鬼婆，手下有兩隻鳥人與一群紅帽子。

## 概況

要塞周圍停著大量**地獄戰爭機器**：像巨大鎧甲拼裝而成、底下裝著車輪的戰車，以[靈魂幣](../items/靈魂幣.md)為燃料。兩隻烏鴉頭的**鳥人**聰明、會讀寫，但聲音被奪走了，只能模仿別人說話；他們懂得操作與改裝戰車。牆上的**紅帽子**守著大門，他們的帽子必須每三天浸一次鮮血。

**鬼婆**是目前對隊伍最友善的阿弗納斯原住民，稱[露露](../npcs/露露.md)為「寶貝」。露露曾在神智不清時被鳥人帶到這裡。

## 經歷

- [在阿弗納斯行軍然後拿到穢液](../episodes/2025-11-08.md)：露露想起這裡，隊伍以這裡為第一個目標。
- [跟錢婆婆交車然後開地獄車車](../episodes/2025-11-15.md)：隊伍從「露露的夢境」中醒來，鬼婆讓隊伍挑選戰車，鳥人送了三枚靈魂幣；隊伍把戰車寄放在這裡。
- [羅剎之歌](../episodes/rec-0040.md)：隊伍的大戰車寄放在這裡。
- [松江南京站](../episodes/songjiang.md)：隊伍回到要塞，鳥人把戰車改成燒穢液。
