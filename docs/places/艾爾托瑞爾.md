# 艾爾托瑞爾

!!! info ""
    艾爾圖加德的城市，人民普遍信仰托姆，也是地獄騎士的故鄉。因至高監督者與扎瑞爾的契約，整座城市墜入了阿弗納斯。

## 現況

城市被鐵鍊吊在**冥河**上方：巨大的黑色石柱插在冥河上，鎖鏈從柱子延伸出來吊著城市。冥河裡的惡魔沿著柱子與鐵鍊往上爬，魔鬼則在柱上把牠們擋下去，雙方激戰不休。

天空赤紅、煙霧瀰漫，原本太陽的位置掛著一顆黑色的球體，也就是伴陽，不時放出藍白色的落雷襲擊城市，地震也週期性發生。大量建築倒塌，魔鬼四處抓人販賣、殺戮，不死生物在街上遊蕩。

## 地理

- **[至高大廳](至高大廳.md)**：斷崖上獻給托姆的白色大理石城堡，城市的政治與宗教中心。
- **托姆之臂／托姆之刃**：城市被一分為二，只靠北邊的托姆之臂與南邊的托姆之刃兩座橋相連。托姆之刃上刻有托姆的聖符，啟動後的聖光能消滅魔鬼。
- **上層區**：靠近至高大廳的豪宅區，[維提克](../characters/維提克.md)的家就在這裡。
- **鐵手會據點**：信仰提爾、托姆與海姆的除惡組織在城中的據點，墜落後幾乎全滅。
- **[大墓地](大墓地.md)**：至高大廳範圍外的墓園，不斷有不死生物湧出。
