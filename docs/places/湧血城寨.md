# 湧血城寨

!!! info ""
    為了保護[扎瑞爾之劍](../items/扎瑞爾之劍.md)而出現的城寨，整座被埋在巨大的血痂裡。劍就插在大教堂的聖座上。

## 概況

城寨被一團約 300 尺高的凝血**血痂**包住，周圍是冒泡的血泥沼澤，白色聖殿的半圓穹頂從頂端破殼而出，纏著漆黑的鐵鏈。正門在血痂最底部；頂端附近有一個惡魔用爪子挖出的洞，可以爬進去。血痂裡嵌著彩繪玻璃窗，只會祝福善良的人。

城寨的入口是一道雙開的黃金大門，門上以天界語寫著（大意）：「對抗邪惡，眾志成城；開啟聖門，須懷純潔之心。」門內射出的聖光會灼燒邪魔與不死生物，卻能讓其他人恢復力量。

門後是一座純白的大教堂，階梯通往聖座，聖座上的石頭裡插著扎瑞爾之劍。[耶諾谷](../npcs/耶諾谷.md)的手下一直在城寨的地道裡挖掘。
