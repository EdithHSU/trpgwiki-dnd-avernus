# 古吉林

!!! info ""
    由扭曲樹木與白骨般的藤蔓構成的迷宮森林，預言家鬼婆[黃鷺鷥](../npcs/黃鷺鷥.md)住在這裡。

## 概況

森林的入口是一扇高約 200 尺、刻著魔鬼對抗惡魔戰爭圖像的巨大黑色拱門。門後唯一的色彩，是樹根、碎石地上的血紅菌類與鏽色水灘；道路狹窄、不斷分岔，天空被樹枝密密麻麻地封住，飛不出去。森林裡有附在樹上的亡魂與詛咒，樹會自己移動，與鬼婆是互相攻擊的世仇。

## 經歷

- [滅魔器與獨角獸](../episodes/monkie-2.md)：[奎恩](../characters/奎恩.md)走進單向的拱門，第一個抵達古吉林。
- [黃鷺鷥唱歌](../episodes/2026-01.md)：隊伍穿越迷宮拜訪鬼婆，替她看家時遭到樹人與女妖化的樹精攻擊。
