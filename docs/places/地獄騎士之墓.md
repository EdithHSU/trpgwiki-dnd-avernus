# 地獄騎士之墓

!!! info ""
    [阿弗納斯](阿弗納斯.md)一座小山丘裡的墓穴，原本由人類興建，用來哀悼地獄騎士。扎瑞爾把當年的騎士靈魂束縛在這裡，並讓死亡騎士[奧蘭蘇斯](../npcs/奧蘭蘇斯.md)鎮守。

## 概況

山頂立著一對約 50 尺高的巨石墓碑，數十名騎士的遺骸跪在前面，額頭抵著劍柄。黑瑪瑙階梯通往山腹裡的玄武岩大門，門上沒有把手或鎖孔，要以古老的地獄騎士誓詞「為了榮耀」才能打開。

墓穴裡冰冷、霧氣瀰漫，有擺滿艾爾托瑞爾貴族骨灰罈的廳堂、束縛靈魂的血色法陣，以及扎瑞爾手下邪術師的墓。最深處的四塊石碑刻著數百個名字，牆上的浮雕是扎瑞爾騎在完全體的[露露](../npcs/露露.md)背上作戰。

隊伍破壞了詛咒、敲去石碑上的名字之後，被困的騎士亡魂都得到了解放。
