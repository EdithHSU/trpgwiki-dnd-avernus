# 哈羅曼之丘

!!! info ""
    以魔鬼騎士[哈魯曼](../npcs/哈魯曼.md)命名的山丘。山路兩旁的鐵樹上，穿刺著當年在扎瑞爾的戰役中逃避職責的艾爾托瑞爾騎士亡魂。

## 概況

一條小路通往陡峭的山頂，路邊是用鐵鍛造的樹，樹枝上穿刺著極度痛苦的騎士，腫脹的蚊蝠吸食著他們的血。碰到騎士時，他頭頂會浮現魔法文字，寫著他的名字與罪名。這些騎士是被詛咒困在這裡的靈魂，從樹上放下來就能解除詛咒、讓他們離開。攻擊哈魯曼的人，附近也會立刻長出一棵寫著罪名的鐵樹。

[露露](../npcs/露露.md)原本以為湧血城寨與扎瑞爾之劍就在這裡，但劍並不在。
