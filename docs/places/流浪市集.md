# 流浪市集

!!! info ""
    在[阿弗納斯](阿弗納斯.md)四處移動的黑市，主人是[馬哈迪](../npcs/馬哈迪.md)。以靈魂幣交易武器、物資與奴隸。

## 概況

一大片色彩鮮豔的帳篷，像地獄裡的綠洲，周圍停著地獄戰車，傳來輕柔的音樂與奇妙的香氣。入口的告示牌寫著：**歡迎所有人，不許打架、不許施法，沒有例外。**

- **煉獄飛昇**：馬哈迪的店，提供高級餐飲、水療與私人包廂，內部像是異次元空間；消費前要簽煉獄語的契約，付清前無法離開。
- **火蛇鍛爐**：火蜥兄弟改裝地獄戰車的工坊，三兄弟身體像大蛇、頭像燃燒的蜥蜴。
- **鬼哭神嚎**：又髒又吵的酒館，可以搭便車，布告欄上貼著軍閥的懸賞。
- 其他：寄送包裹的「從這裡到阿弗納斯」、賣惡魔穢液的店、幼蟲牧場，以及一間只收金幣、不收靈魂幣的理髮帳篷。
