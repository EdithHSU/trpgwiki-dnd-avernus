# 黃鷺鷥唱歌

!!! abstract "本集概要"
    隊伍走進[骨脊林](../places/骨脊林.md)，拜訪以童謠說話的預言家鬼婆[紅露絲](../npcs/紅露絲.md)。替她看家時，樹人與女妖化的樹精差點讓隊伍全滅。占卜之後，隊伍決定先完成與[拉爾薩拉](../npcs/拉爾薩拉.md)的約定，找到被提亞瑪特詛咒成鏈魔的至高天巨人[烏爾德拉克](../npcs/烏爾德拉克.md)，他也加入了隊伍。本集最後，隊伍抵達[殘忍的阿克漢](../npcs/殘忍的阿克漢.md)之塔。

!!! note "關於上一集"
    本集直接接續[滅魔器與獨角獸](monkie-2.md)：[奎恩](../characters/奎恩.md)先走進拱門抵達骨脊林，其他人隨後跟進。

## 劇情

### 骨之森林

一扇高約 200 尺、刻著**魔鬼對抗惡魔戰爭**圖像的巨大黑色拱門，門裡像有一道火牆。門後是扭曲的樹木與白骨般的藤蔓糾結成的森林，道路狹窄、不斷分岔，像迷宮；天空被樹枝密密麻麻地封住，飛不出去。[凱侖](../characters/凱侖.md)帶路穿越迷宮，來到中央的開闊處。

### 唱歌的鬼婆

小屋入口掛著屍骨與斷肢，走出來的老婦人穿著骨頭縫製的裙子，脖子掛著嬰兒大小的顱骨項鍊，嘴裡唱著**精靈語的童謠**。她每句話都用童謠唱出來，她就是**[紅露絲](../npcs/紅露絲.md)**。懂精靈語的[奎恩](../characters/奎恩.md)順著童謠接唱，她唱著「歡迎你，旅行者」，招手讓大家進屋。

隊伍想問她如何解除[拉爾薩拉](../npcs/拉爾薩拉.md)與[扎瑞爾](../npcs/扎瑞爾.md)的契約，以及[扎瑞爾之劍](../items/扎瑞爾之劍.md)的位置。[紅露絲](../npcs/紅露絲.md)說拉爾薩拉的事不用另外收費，但有一件事想拜託：**她想去洗澡**，上一次洗澡是幾個世紀前的事了，請隊伍幫她**看家**幾個小時。她劃破手，血在地上流成一張地圖，她在上面一點就傳送消失了。

### 看家：樹人與女妖化的樹精

[奎恩](../characters/奎恩.md)易容成鬼婆的樣子，在屋裡到處用童謠唱怪話，撐了一個多小時。然後兩個灰色的樹精幽魂和一棵會走路的**巨型樹人**逼近，樹人說：「**[紅露絲](../npcs/紅露絲.md)必須付出代價。**」三棵巨樹一起猛砸小屋。

- 凱侖藉[加葛斯之盾](../items/加葛斯之盾.md)放出火球，重創了怕火的樹人。
- 樹精幽魂發出**哭嚎**，[歐蓓](../characters/歐蓓.md)、[凱侖](../characters/凱侖.md)、[蓋比](../characters/蓋比.md)、[奎恩](../characters/奎恩.md)等人當場倒地。
- [阿弗](../npcs/阿弗.md)拿起鬼婆架上的**巨大化藥水**一口喝下，變成巨型，抓住了樹人。
- [露露](../npcs/露露.md)現學醫療術救醒歐蓓；一直只想旁觀的[獨角獸](../npcs/月色.md)也用角救起凱侖與奎恩。
- 凱侖起身後救起蓋比，並舉起聖徽驅散不死生物。原來樹人與樹精都是不死生物，三者驚恐地逃跑了。

小屋被毀了一半。隊伍讓[阿弗](../npcs/阿弗.md)變得更大，用手指把骨頭像薑餅屋一樣拼回去，又用修復術修好破掉的藥水瓶，順便把屋子裝飾得可愛一點。逃跑時倒下的樹，樹洞裡有一具侏儒的白骨，戴著一頂**易容帽**，[凱侖](../characters/凱侖.md)為他埋葬、禱告。

### 占卜

洗得乾乾淨淨的[紅露絲](../npcs/紅露絲.md)回來，唱著說她明白隊伍經歷了什麼，「一切都是必要的」。

- **關於[拉爾薩拉](../npcs/拉爾薩拉.md)**：要擺脫與[扎瑞爾](../npcs/扎瑞爾.md)的契約，拉爾薩拉必須喝下**巨人之血**。在[阿弗納斯](../places/阿弗納斯.md)，能提供的是**[烏爾德拉克](../npcs/烏爾德拉克.md)**，「一個被困在魔鬼身體裡的巨人」，她在地圖上標出了位置。
- 隊伍花 3 枚[靈魂幣](../items/靈魂幣.md)占卜三個問題。清楚聽到的答案是：**扎瑞爾現在沒有在監視隊伍**。從之後的對話來看，占卜也指出**在惡魔誕生之地找不到[扎瑞爾之劍](../items/扎瑞爾之劍.md)**（[露露](../npcs/露露.md)補充，那裡也許仍有線索），而露露聽了占卜後，相信扎瑞爾有可能變回善良。

### 露露的決心

[露露](../npcs/露露.md)說，[貝爾](../npcs/貝爾.md)在[扎瑞爾](../npcs/扎瑞爾.md)之前統治這裡，又是扎瑞爾的敵人，**也許很清楚湧血城寨的位置**。想到貝爾，她打了個冷顫，但說為了喚醒扎瑞爾可能存在的良知，再危險也會去。隊伍決定**先完成與[拉爾薩拉](../npcs/拉爾薩拉.md)的約定**，前往[烏爾德拉克](../npcs/烏爾德拉克.md)所在地，並在[骨脊林](../places/骨脊林.md)長休，升到 8 級。

旅途中，[露露](../npcs/露露.md)說她認為是**[扎瑞爾](../npcs/扎瑞爾.md)把她送離[阿弗納斯](../places/阿弗納斯.md)的**，那是扎瑞爾心中殘存的善良。

### 烏爾德拉克

一頂巨大的巨人頭盔和一把巨劍埋在灰燼中，劍柄嵌著一顆散發紅光的寶石，頭盔裡住著一隻**鏈魔**。他說自己是巨人，同時也是惡魔：他原本是為了**殺死提亞瑪特**而來，失敗後被**提亞瑪特的詛咒**困在這個身體裡。要恢復原狀，他需要親手取得**提亞瑪特的血**，而那瓶血在提亞瑪特的信徒**[殘忍的阿克漢](../npcs/殘忍的阿克漢.md)**身上。

他其實是一名**至高天巨人**，來自天界、受神的旨意前來消滅提亞瑪特，在[阿弗納斯](../places/阿弗納斯.md)待了上千年，處境和[扎瑞爾](../npcs/扎瑞爾.md)很像。他把劍柄上的**龍珠寶珠**交給隊伍，說那是[阿克漢](../npcs/殘忍的阿克漢.md)會感興趣的東西。[奎恩](../characters/奎恩.md)說服他**與隊伍同行，直到打敗扎瑞爾**。[烏爾德拉克](../npcs/烏爾德拉克.md)說，他在這裡等了幾千年，等的就是這一刻。

### 阿克漢之塔

黑色高塔聳立在地平線上，城牆插滿焦黑骷髏頭的鐵刺，塔尖分成五根像爪子般刺向天空，一條沾滿灰燼的巨龍盤旋在塔上，城牆上巡邏的是腐爛程度不一的不死守衛。這裡接近提亞瑪特的神殿。本集在這裡結束。

## 重要決定

1. 答應鬼婆幫她看家，換取拉爾薩拉需要的情報。
2. 花 3 枚[靈魂幣](../items/靈魂幣.md)占卜。
3. **先完成與[拉爾薩拉](../npcs/拉爾薩拉.md)的約定**，聖劍的線索寄望於[貝爾](../npcs/貝爾.md)。
4. 答應替[烏爾德拉克](../npcs/烏爾德拉克.md)從[阿克漢](../npcs/殘忍的阿克漢.md)手上取得提亞瑪特之血，並說服他同行直到打敗[扎瑞爾](../npcs/扎瑞爾.md)。

## 劇情重點

- **陣營回歸**：[凱侖](../characters/凱侖.md)與[歐蓓](../characters/歐蓓.md)恢復善良。
- **全滅危機**：一聲哭嚎放倒半數隊員，靠[露露](../npcs/露露.md)與[獨角獸](../npcs/月色.md)救回。
- **露露的決心**：相信[扎瑞爾](../npcs/扎瑞爾.md)當年送走她是殘存的善良，願意冒險面對[貝爾](../npcs/貝爾.md)。
- **[烏爾德拉克](../npcs/烏爾德拉克.md)**：被提亞瑪特詛咒成鏈魔的至高天巨人，成為新的同伴。
