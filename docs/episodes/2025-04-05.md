# 惡魔不飛

!!! abstract "本集概要"
    隊伍在博德之門追查與九獄勾結的[萬瑟姆普家族](../npcs/萬瑟姆普家族.md)。他們以安置難民為名向萬瑟姆普家的大少爺借錢，活捉一隻偽裝成雕像的小魔鬼問出幕後主人，最後請一個曾受隊伍救命之恩的貴族寫了引薦信，準備以傭兵身分打入萬瑟姆普家。

!!! note "這不是第一次團務"
    本集開始時，隊伍已經抓到萬瑟姆普家的公子摩特洛克、救過貴族賈斯索家族，也和城裡的斯泰爾曼、波提爾兩位公爵有往來，可見之前還有沒錄到音的團務。

## 劇情

### 與萬瑟姆普家大少爺會面

酒館樓下的角落沙發區，三名壯漢守著[萬瑟姆普家族](../npcs/萬瑟姆普家族.md)的大少爺**阿姆利克**，他正在處理帳務。隊伍已經知道這個家族與死亡三神教、九獄的勢力勾結，於是上前搭話，以「想借錢安置艾爾圖加德難民」為由接近他。

[維提克](../characters/維提克.md)以地獄騎士的身分出面交涉。阿姆利克開出十天期限、一成多利息的條件，隊伍簽下借據。隊伍私下的盤算是：反正之後要扳倒[萬瑟姆普家](../npcs/萬瑟姆普家族.md)，這筆錢不用還。

### 分頭行動

當晚隊伍分成兩路：一路去拜訪城裡的公爵，商談情報與資金合作；另一路上街散布謠言、發放傳單，同時尋找先前遇過的小魔鬼的線索。隊伍也決定暫時不歸還先前向焰拳隊長借來的通行徽章，以保持行動自由。

### 活捉偽裝的小魔鬼

回到酒館的花園時，隊伍識破噴水池旁一座雕像其實是負責監視的**小魔鬼**。妖火讓牠現形，牠受驚想飛走，隊伍改用睡眠術活捉，帶回房間審問。

小魔鬼起初威嚇「我的主人會殺了你們」，在利誘與逼問下透露：

- 牠的主人是[萬瑟姆普家](../npcs/萬瑟姆普家族.md)深居簡出的公子**瑟斯維爾**，透過心靈連結操控這些小魔鬼當作耳目，凡事都讓小魔鬼代勞。
- 主人房裡有一個受到嚴密保護、連小魔鬼都不准靠近的**重要盒子**。

隊伍決定不殺牠，考慮長期關押，甚至把牠當成反向的情報來源。

### 審問被俘的公子與兩位公爵

隊伍以偵測思想窺探先前抓到的[萬瑟姆普家](../npcs/萬瑟姆普家族.md)公子摩特洛克，讀到他對瑟斯維爾的崇拜，以及怕餓、怕被殺的憂慮。

隊伍也討論了要怎麼與兩位公爵往來：波提爾公爵暗示不完全信任斯泰爾曼公爵，斯泰爾曼公爵則同意每天提供隊伍活動資金。隊伍決定兩邊都保持聯繫，有條件地交換資訊，不把雞蛋放在同一個籃子裡。

### 取得引薦信

隊伍前往上城區，拜訪曾受隊伍救命之恩、如今家道中落的貴族**賈斯索家族**。家主克里姆起初不太耐煩，得知來意後念及恩情，透露[萬瑟姆普家](../npcs/萬瑟姆普家族.md)的三個兒子分別出自三段婚姻，這個家族在貴族圈裡也「幾乎沒有真心朋友，只有巴結者」。最後他同意寫一封**引薦信**，推薦隊伍是「優秀且值得信賴的傭兵」。

## 重要決定

1. 以安置難民為名向阿姆利克借錢，實際上是為了接近萬瑟姆普家。
2. 活捉監視的小魔鬼，留牠一命作為情報來源。
3. 在兩位公爵之間採取兩邊都保持聯繫的路線。
4. 以傭兵身分，透過引薦信滲透[萬瑟姆普家族](../npcs/萬瑟姆普家族.md)。

## 劇情重點

- **深居簡出的瑟斯維爾**：透過小魔鬼遠端行動，房裡藏著一個神秘的盒子。
- **[萬瑟姆普家](../npcs/萬瑟姆普家族.md)的裂痕**：三個兒子分別出自三段婚姻，家族內部本身就有矛盾。
