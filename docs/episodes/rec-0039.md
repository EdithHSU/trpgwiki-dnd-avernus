# 苦痛之息的審判

!!! abstract "本集概要"
    隊伍擊退大哥布林暴走族，被丟下的角魔向隊伍投降，他就是懸賞板上的軍閥[苦痛之息](../npcs/苦痛之息.md)。[烏爾德拉克](../npcs/烏爾德拉克.md)恢復至高天巨人的真身，留下巨人之血後帶著[月色](../npcs/月色.md)離開。隊伍為了苦痛之息的去留爆發善惡衝突，最後由[凱侖](../characters/凱侖.md)占卜、[蓋比](../characters/蓋比.md)處決。隊伍用巨人之血替[拉爾薩拉](../npcs/拉爾薩拉.md)解約，拿到去見[貝爾](../npcs/貝爾.md)的介紹信。

!!! note "關於這段錄音"
    這是錄音筆的原始檔，沒有集名；開場提到「今天是情人節」，推測錄音日期是 2026-02-14。內容直接接續[殘忍的阿克漢](rec-0038.md)的伏擊戰，角色為 9 級。

## 劇情

### 擊退大哥布林暴走族

戰鬥接續上一集。[歐蓓](../characters/歐蓓.md)的力場牆把一部分大哥布林隔在另一側，他們射出的箭都被牆彈了回來。

- 一隻**沒有翅膀的角魔**在大哥布林將軍格拉杰・卡卡朱克的號令下行動，一刀把[安格](../characters/安格.md)的小魔鬼劈成兩半。
- [維提克](../characters/維提克.md)帶著凱侖給的神聖武器，一擊打倒一名隊長；[詹德](../npcs/詹德.md)以至聖斬殺死攻擊[露露](../npcs/露露.md)的大哥布林，但他的劍發出的光帶著一點邪氣。
- [蓋比](../characters/蓋比.md)對角魔擲出大成功，造成重創。
- [烏爾德拉克](../npcs/烏爾德拉克.md)完成變身，現出 25 尺高的**至高天巨人**真身，以奧術閃電把將軍打得全身焦黑。
- [凱侖](../characters/凱侖.md)用盾牌把將軍從機車上撞下來。將軍倒地時高舉武器，說自己「絕不逃避任何戰鬥」，隨後被[奎恩](../characters/奎恩.md)殺死。
- 剩下的大哥布林爬上大型戰車倒車撤退，**把角魔丟下**，也留下了四台機車。

角魔放下武器，以心靈感應對[安格](../characters/安格.md)說：「我投降。」

### 巨人與獨角獸的告別

[烏爾德拉克](../npcs/烏爾德拉克.md)正要對角魔射出光束，被一名隊員制止：「我們不會對投降的敵人趕盡殺絕。」巨人割破手指，給了隊伍**一加侖的至高天巨人之血**。他說自己會異界傳送，可以帶最多八人離開[阿弗納斯](../places/阿弗納斯.md)；隊伍請他留下幫忙，他說自己正是因為任務失敗才被困在這裡，要回去再修煉幾百年。

[維提克](../characters/維提克.md)以**托姆的恩賜**讓烏爾德拉克恢復原本的善良。維提克也問[詹德](../npcs/詹德.md)要不要一起離開，詹德說，這一次他不會再拋下能真正擊敗邪惡的機會，也不會再背棄任何夥伴。維提克給了他一個兄弟般的擁抱。

[月色](../npcs/月色.md)本來要跟巨人一起走，聽到詹德的決心後流著淚祝福隊伍，替所有人補滿生命值，並給了大家**最後一次改變陣營的機會**。兩者的異界傳送在阿弗納斯被扭曲，看起來像是被一個小黑洞吞了進去，讓隊伍有點不安。

### 苦痛之息

角魔只能以心靈感應一次對一個人說話，由[安格](../characters/安格.md)代為傳達。他就是懸賞板上的軍閥**[苦痛之息](../npcs/苦痛之息.md)**，本名**萊澤斯**：

- 他原本是[貝爾](../npcs/貝爾.md)的部下，曾和貝爾密謀推翻[扎瑞爾](../npcs/扎瑞爾.md)，但內部出了間諜。扎瑞爾把他**降級成角魔**、拔掉翅膀，並詛咒他**不能說話，也不能簽訂契約**。
- 被問到扎瑞爾為什麼不殺叛徒，他回答：「有時候，活著比死更痛苦。」
- 他說自己會繼續與扎瑞爾對抗；如果隊伍不認同，在這裡殺了他也沒關係。

[凱侖](../characters/凱侖.md)等人覺得他很誠懇，確實像曾經的貝爾大將；安格則看出他只是為了活下去才這麼說。[歐蓓](../characters/歐蓓.md)主張留他當熟悉阿弗納斯勢力的嚮導。[阿弗](../npcs/阿弗.md)對他很感興趣：他活得痛苦，卻仍選擇活下去。

### 善惡的衝突

[蓋比](../characters/蓋比.md)突然一箭射向苦痛之息，被[安格](../characters/安格.md)擋下。蓋比爆發了：阿弗、加格斯之盾、來路不明的吸血鬼騎士，前幾次都忍了，這次不能再忍。安格反駁，這些黑暗的存在至今都在幫忙，在地獄裡借用黑暗的力量沒什麼不好。爭執中也翻出[凱侖](../characters/凱侖.md)一直沒告訴大家：**盾牌裡的存在會說話**。

[詹德](../npcs/詹德.md)以前軍官的身分提議：每個人替自己帶進隊伍的「不安定因素」設下底線、負起擔保的責任。

### 伊爾馬特的審判

[凱侖](../characters/凱侖.md)提議以**占卜術**問伊爾馬特：殺了苦痛之息，對隊伍在阿弗納斯的旅程是吉是凶。他把撿來的骨頭折碎撒在地上，骨頭先排成一種結果，接著底下有東西緩緩震動，把骨頭推成了相反的結果，彷彿有人刻意在改變答案。最後的結論是：**殺了他會帶來好結果**。

凱侖遲疑地宣布，這是伊爾馬特的審判。[蓋比](../characters/蓋比.md)一言不發，親手殺死了苦痛之息，他倒地時吐出最後一口白煙。[阿弗](../npcs/阿弗.md)看著這一幕，第一次想到攻擊某人也可以是一種「審判」。[安格](../characters/安格.md)則拿著角魔身上的穢液走到蓋比面前：「比起憎惡這些邪惡的東西，不如利用它，這才是在阿弗納斯生存的道理。」

### 黏液峽谷的籠子

前往[拉爾薩拉](../npcs/拉爾薩拉.md)那裡的途中，隊伍迷了路，來到一座峽谷：冥河的一條支流從懸崖瀉入谷底，注入像在呼吸般起伏的**綠色黏液湖**。懸崖邊的鐵籠反覆把一隻**尤格洛斯魔**巴茲特浸進黏液再拉上來。一名隊員用力場牆擋住籠子，另一人砍斷了鎖鏈。

這隻尤格洛斯魔曾在[貝爾](../npcs/貝爾.md)手下做事，因為偷了一枚靈魂幣被關在這裡。他開出條件：放他出來，就教隊伍用黏液塑造魔法僕人，並帶隊伍去**[貝爾的熔爐](../places/貝爾的熔爐.md)**。一名隊員把手指伸進黏液，聽到一個聲音不斷重複「要對貝爾復仇」：據說這片黏液原本是一隻強大的魔鬼，現在已經失去理智。

[安格](../characters/安格.md)想學黏液僕人的方法，甚至考慮學完再處理掉他；[歐蓓](../characters/歐蓓.md)反對「先欺騙利用再殺掉」，其他人也不贊成。最後隊伍不放他、也不殺他，讓籠子留在岸上，就此離開。

### 拉爾薩拉的介紹信

隊伍回到滅魔之地，[拉爾薩拉](../npcs/拉爾薩拉.md)從地底浮現，急著問「完成了嗎？」他只喝了一點至高天巨人之血，就傳來像鎖鏈被砍斷的破裂聲，讓他欣喜若狂。他取出石板，以煉獄語寫下承諾的**給[貝爾](../npcs/貝爾.md)的介紹信**，指出貝爾熔爐的方向，但拒絕同行。剩下的巨人之血由隊伍保管。

這晚長休後，一名隊員的陣營轉為邪惡（下一集確認是[維提克](../characters/維提克.md)）。維提克的托姆之力已經用在烏爾德拉克身上，暫時沒有人能把陣營拉回來。

### 流浪市集的賭局

前往貝爾的熔爐要兩天，四台機車的燃料快用完了。就在機車沒油時，熟悉的[流浪市集](../places/流浪市集.md)剛好出現在眼前。隊伍在煉獄飛昇玩了 d20 比大小與三龍牌，[凱侖](../characters/凱侖.md)大贏；[安格](../characters/安格.md)則要跟凱侖借錢復活小魔鬼，欠凱侖的債越來越多。

## 重要決定

1. 接受[苦痛之息](../npcs/苦痛之息.md)投降，不讓巨人趕盡殺絕；之後以凱侖的占卜作為伊爾馬特的審判，由蓋比處決他。
2. 婉拒[烏爾德拉克](../npcs/烏爾德拉克.md)帶人離開阿弗納斯的提議；[詹德](../npcs/詹德.md)表明要留下。
3. 維提克把托姆的恩賜用在烏爾德拉克身上，讓他恢復善良。
4. 籠中的尤格洛斯魔巴茲特：不欺騙利用、不放出、也不殺。
5. 以巨人之血替[拉爾薩拉](../npcs/拉爾薩拉.md)解約，取得給貝爾的介紹信，下一個目標是[貝爾的熔爐](../places/貝爾的熔爐.md)。

## 劇情重點

- **[苦痛之息](../npcs/苦痛之息.md)**：原是[貝爾](../npcs/貝爾.md)的部將，被[扎瑞爾](../npcs/扎瑞爾.md)降級、拔翅、詛咒。扎瑞爾對付叛徒的方式，是讓人「活得比死更痛苦」。
- **巨人與獨角獸離隊**：[烏爾德拉克](../npcs/烏爾德拉克.md)恢復原貌，帶著[月色](../npcs/月色.md)離開阿弗納斯。
- **隊伍內的善惡衝突**：[蓋比](../characters/蓋比.md)對隊上越來越多的邪惡存在忍無可忍，與[安格](../characters/安格.md)正面衝突。
- **被動過手腳的占卜**：凱侖的骨頭被某種力量推成相反的結果，是誰在改變答案仍是謎。
- **拉爾薩拉的約定完成**：隊伍終於拿到見貝爾的介紹信。
