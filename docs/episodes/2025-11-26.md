# 酒館魅魔好難纏

!!! abstract "本集概要"
    在酒館「鬼哭神嚎」，隊伍看到三名軍閥的懸賞單，[安格](../characters/安格.md)被魅魔服務生纏上。[馬哈迪](../npcs/馬哈迪.md)在晚宴上談起[耶諾古](../npcs/耶諾古.md)與[扎瑞爾](../npcs/扎瑞爾.md)，並暗示自己能轉介「實現任何願望」的交易。[維提克](../characters/維提克.md)被市集裡一位理髮的老婦人開導，決定心懷感激地使用[靈魂幣](../items/靈魂幣.md)。隊伍買下兩隻巨型太空倉鼠當坐騎。

## 劇情

### 鬼哭神嚎的懸賞單

[安格](../characters/安格.md)、[歐蓓](../characters/歐蓓.md)、[蓋比](../characters/蓋比.md)走進酒館**鬼哭神嚎**：跟典雅的煉獄飛昇相反，又髒又吵，魔鬼、提夫林、卓爾、人類混在一起。布告欄上最吸引人的是附近三名軍閥的懸賞：**[苦痛之息](../npcs/苦痛之息.md)**、**菲奧諾**、**元首科維克**。他們開著地獄戰車四處移動，彼此憎恨，懸賞對方的人頭。

招呼他們的是一名深紅色皮膚、頭上有小角的**魅魔**服務生。隊伍點了巨型太空倉鼠排，問起軍閥時，她露出危險的笑容：「你們也不是第一組這樣的人。」接著她把手搭上[安格](../characters/安格.md)的手：「我只對你有興趣。」安格感覺到魔法能量流進心裡，覺得她很有魅力。[歐蓓](../characters/歐蓓.md)靠過去提醒安格別喝多了，三人狼狽地離開酒館。

### 馬哈迪的晚宴

煉獄飛昇的晚宴繼續，主菜有炙烤食人魚、香烤野豬人、斧喙鳥肉條。[奎恩](../characters/奎恩.md)問[馬哈迪](../npcs/馬哈迪.md)聽過**[耶諾古](../npcs/耶諾古.md)**嗎，馬哈迪的笑容加深，像在隱藏什麼。他說這一帶都是託**[扎瑞爾](../npcs/扎瑞爾.md)**的福才能做生意，但耶諾古不這麼想；耶諾古來自深淵，在這裡被殺死也會回深淵復活，不建議和他起衝突。

[奎恩](../characters/奎恩.md)說「我們是[扎瑞爾](../npcs/扎瑞爾.md)最忠心的朋友」，想幫她拔掉這根眼中釘。[凱侖](../characters/凱侖.md)聽了皺眉、抓起武器瞪著奎恩，連[馬哈迪](../npcs/馬哈迪.md)都笑說：「如果你想為扎瑞爾效力，這兩個夥伴好像不太適合。」

[奎恩](../characters/奎恩.md)感嘆以人類的壽命可能走不到終點。[馬哈迪](../npcs/馬哈迪.md)說，他有專門給重要客人的特別服務：**他可以「轉介」能實現任何願望的對象**，當然對方會要求相應的代價。提到拯救[艾爾托瑞爾](../places/艾爾托瑞爾.md)時，馬哈迪嘆氣：「那些人的名字都在契約上，艾爾托瑞爾和它的人民現在都屬於[扎瑞爾](../npcs/扎瑞爾.md)，地表的規則在這裡不適用。」[凱侖](../characters/凱侖.md)冷哼：「我們會找到辦法解決的。」

### 理髮師老婦人

[維提克](../characters/維提克.md)在市集閒逛時，看到一間理髮帳篷寫著「1 GP，**不收[靈魂幣](../items/靈魂幣.md)**」。店主**布妮**是一位翹著腳抽菸斗的白髮老婦人，帳篷裡有舒服的草藥味。這是維提克在地獄裡最療癒的體驗。

老婦人說，她看過太多邪惡，試著阻止卻大多徒勞，於是學會與邪惡相處、在這裡觀察，「必要時也許會出手」。[維提克](../characters/維提克.md)說，自己無法像隊友一樣接受[靈魂幣](../items/靈魂幣.md)，擔心自己的堅持成為隊伍的阻礙。老婦人反問：你願意為願景犧牲到什麼程度？是要和使用靈魂幣的人同行，還是只想保護自己的高潔而停在原地？

**[維提克](../characters/維提克.md)決定「心懷感激地使用[靈魂幣](../items/靈魂幣.md)」**。老婦人送給這位托姆的牧師**巴哈姆特的祝福**，維提克離開時，在帳篷裡瞥見一條遠古金屬色巨龍的影子，只有一瞬間。

[維提克](../characters/維提克.md)回到戰車後告訴[歐蓓](../characters/歐蓓.md)，他願意承受燒掉[靈魂幣](../items/靈魂幣.md)、一路聽著靈魂哀嚎的痛苦。

### 太空倉鼠農場

晚宴的最後一道菜是油炸巨型太空倉鼠。[馬哈迪](../npcs/馬哈迪.md)打開店裡的另一道門：裡面是一格格透明玻璃倉，關著**和熊一樣大的太空倉鼠**。他說從沒看過有人把牠們當坐騎，覺得很新奇。隊伍以一隻 100 金幣的價格，**買下兩隻巨型太空倉鼠**。吃完整套晚宴的人，都獲得了英雄宴的效果。

## 重要決定

1. 把三名軍閥的懸賞列為賺取[靈魂幣](../items/靈魂幣.md)的可能目標。
2. [安格](../characters/安格.md)沒有接受魅魔的邀請。
3. [維提克](../characters/維提克.md)改為願意心懷感激地使用靈魂幣。
4. 買下兩隻巨型太空倉鼠當坐騎。

## 劇情重點

- **[馬哈迪](../npcs/馬哈迪.md)與[扎瑞爾](../npcs/扎瑞爾.md)**：[流浪市集](../places/流浪市集.md)仰賴扎瑞爾才能經營；馬哈迪暗示能轉介實現願望的交易。
- **[耶諾古](../npcs/耶諾古.md)**：來自深淵、殺了也會復活，越接近扎瑞爾越可能遇上。
- **[奎恩](../characters/奎恩.md)與[凱侖](../characters/凱侖.md)的分歧**：奎恩自稱扎瑞爾的朋友，凱侖當場抓起武器瞪他。
- **神秘的理髮師布妮**：只收金幣、給予巴哈姆特的祝福，身影與遠古金屬龍重疊。
