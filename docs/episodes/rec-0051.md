# 露露的回憶：艾德爾格蘭

!!! abstract "本集概要"
    隊伍在拔出[扎瑞爾之劍](../items/扎瑞爾之劍.md)時，被一道光帶進[露露](../npcs/露露.md)的回憶，來到被豺狼人侵擾的小鎮[艾德爾格蘭](../places/艾德爾格蘭.md)。教堂前的[扎瑞爾](../npcs/扎瑞爾.md)雕像散發出灼燒邪魔的聖光。[安格](../characters/安格.md)用風牆術殺死被詛咒的平民，挨了[維提克](../characters/維提克.md)一巴掌。露露想起自己曾載著扎瑞爾對抗[耶諾谷](../npcs/耶諾谷.md)，而耶諾谷本人也在本集最後登場。

!!! note "關於這段錄音"
    這是錄音筆的原始檔，沒有集名，錄音日期不明。內容直接接續[湧血城寨的聖門](rec-0050.md)結尾的艾德爾格蘭之戰，角色為 12 級。

## 劇情

### 雕像的聖光

隊伍在[艾德爾格蘭](../places/艾德爾格蘭.md)鎮上的教堂前作戰，教堂外有一座**[扎瑞爾](../npcs/扎瑞爾.md)的雕像**：穿著鎧甲、背有翅膀的天使。[阿弗](../npcs/阿弗.md)、[詹德](../npcs/詹德.md)與[安格](../characters/安格.md)的小魔鬼都進不了這片聖地。

一隻體型巨大的**六臂豺狼人**在魔法閃光中傳送到戰場，對[蓋比](../characters/蓋比.md)連砍六下。這時，**[扎瑞爾](../npcs/扎瑞爾.md)的雕像發出強烈的神聖白光**，雕像下刻著：「扎瑞爾，[艾德爾格蘭](../places/艾德爾格蘭.md)的守護者」。邪魔踏進這圈光芒，就會被白色火焰灼燒。

- [歐蓓](../characters/歐蓓.md)把重傷的[蓋比](../characters/蓋比.md)變成**霸王龍**，讓蓋比當肉盾。
- [凱侖](../characters/凱侖.md)走到雕像前向蘭森德祈禱，獲得了防護邪惡與驅逐邪魔的力量。
- 六臂豺狼人最後被放逐。

### 被穢液詛咒的守衛

五名**全身沾滿惡魔穢液**、眼神飢渴瘋狂的人類守衛衝了過來。他們**被詛咒了**，原本是善良的人。隊伍決定手下留情：霸王龍把守衛咬昏，[凱侖](../characters/凱侖.md)的靈體武器一拳打在守衛臉上，[歐蓓](../characters/歐蓓.md)也不敢打死人。

只剩兩名重傷、已經構不成威脅的守衛時，[安格](../characters/安格.md)對他們施放**風牆術**，兩人被吹上半空、肢體碎裂而死。[露露](../npcs/露露.md)感到強烈的厭惡與憤怒，這股「**露露之怒**」讓安格獲得了一級力竭。

### 維提克的巴掌

[維提克](../characters/維提克.md)賞了[安格](../characters/安格.md)一巴掌：「你看清楚自己做了什麼！到現在還認為你不需要幫助嗎？你殺了兩個無辜的平民。」安格反駁那些人已經被穢液控制，風牆能讓戰鬥最快結束，「只要對我有利，我就會這麼做」。[歐蓓](../characters/歐蓓.md)則自責當時自己的猶豫讓攻擊落空，事後試著用安格能接受的方式勸他。[凱侖](../characters/凱侖.md)心懷悲傷，但決定不苛責安格。

### 艾德爾格蘭的歷史

[凱侖](../characters/凱侖.md)治療了倖存的守衛，他們醒來後恢復了神智，說大量惡魔突然出現，是**[耶諾谷](../npcs/耶諾谷.md)**的手下。[艾德爾格蘭](../places/艾德爾格蘭.md)長年飽受豺狼人侵擾，一位蘭森德的牧師向神祈禱，蘭森德被鎮民的勇氣感動，**派[扎瑞爾](../npcs/扎瑞爾.md)來擊敗豺狼人**，鎮民因此立起這座雕像。教堂的女祭司**艾莎・明星**為隊伍祈禱，說隨時可以進來避難。

### 露露想起來了

隊伍回想自己是怎麼來到這裡的：在**拔[扎瑞爾之劍](../items/扎瑞爾之劍.md)**時，眼前一道光，就出現在這座小鎮。

一個半透明的幻影，一名身穿板甲的人類女性，指向[露露](../npcs/露露.md)。**露露的眼睛變白，說「我想起來了」**：她曾經和[扎瑞爾](../npcs/扎瑞爾.md)在這裡並肩作戰，那時她跟霸王龍一樣大，扎瑞爾騎著她；她們對上最強的敵人，就是豺狼人的領主[耶諾谷](../npcs/耶諾谷.md)。隊員推測，照歷史扎瑞爾應該在場，現在可能是由隊伍取代了扎瑞爾的位置。

### 耶諾谷登場

一隻笨重如猩猩的**巴古拉魔**跳過聖光衝進後排，隨後被放逐；一隻豺狼人頭領帶著六隻豺狼人衝來，被[露露](../npcs/露露.md)的號角、[蓋比](../characters/蓋比.md)的箭、[安格](../characters/安格.md)的荊棘與[凱侖](../characters/凱侖.md)的火球消滅。

一陣狂野悚人的笑聲讓戰場安靜下來，**[耶諾谷](../npcs/耶諾谷.md)**從迷霧中走出：揮舞著連枷的巨型豺狼人，血盆大口滴著鮮血。他衝進聖光，身上燃起白色火焰。隱形的[維提克](../characters/維提克.md)以聖劍連續攻擊，但耶諾谷體型太大，傷口看起來很小，他依然面帶笑容。耶諾谷瘋狂擺頭，咬中了身邊的[蓋比](../characters/蓋比.md)、[凱侖](../characters/凱侖.md)、[歐蓓](../characters/歐蓓.md)與[露露](../npcs/露露.md)。

本集在這裡結束。

## 劇情重點

- **[露露](../npcs/露露.md)的回憶**：拔[扎瑞爾之劍](../items/扎瑞爾之劍.md)時，被傳進[扎瑞爾](../npcs/扎瑞爾.md)還是天使時守護過的小鎮。
- **扎瑞爾的雕像**：「[艾德爾格蘭](../places/艾德爾格蘭.md)的守護者」，散發灼燒邪魔的聖光。
- **[安格](../characters/安格.md)的邪惡**：用風牆術殺死被詛咒的平民，招來露露之怒與[維提克](../characters/維提克.md)的巴掌。
- **[耶諾谷](../npcs/耶諾谷.md)親臨**：豺狼人的惡魔領主在露露的回憶中登場。
