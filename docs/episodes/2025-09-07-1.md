# 你做了什麼（1）

!!! abstract "本集概要"
    前往[大墓地](../places/大墓地.md)的路上，隊伍遠遠望見一名騎著夢魘的強大騎士，決定繞路避開。接著遇上一具會爆出火焰的燒焦屍體，[雷亞](../npcs/雷亞.md)一劍將它劈成兩半。隊伍取得一把銀劍與一瓶神秘的藥水，抵達大墓地。

!!! note "同一天的兩段錄音"
    這天的團錄分成兩個檔案，本頁是前半段，後半段見[你做了什麼（2）](2025-09-07-2.md)。

## 劇情

### 騎著夢魘的騎士

隊伍從高處望見遠方一名騎士，騎著一匹**鬃毛與尾巴燃燒著火焰的黑馬**。隊員認出那是**夢魘**，是魔鬼、惡魔、邪惡騎士等強大存在的坐騎。

[露露](../npcs/露露.md)以心靈感應警告，這是非常強大的存在。騎士身材高大壯碩，穿著帶刺的板甲，看起來身經百戰，比隊伍從博德之門一路以來遇過的所有對手都強。隊伍以「現在拯救大公更重要」為由決定繞路，騎士剛好朝另一個方向前進，雙方順利錯開。

### 燃燒的殭屍

快到[大墓地](../places/大墓地.md)時，一具**燒焦的人形屍體**從巷子裡走出來，手握一把鍍銀長劍。牠的臉完全焦黑，身體不停轉動，像是在尋找什麼。

隊伍判斷牠已經變成不死生物，讓牠安息也是一種慈悲，決定偷襲。一名隊員拿著匕首繞到背後，一靠近，**屍體全身就爆出火焰**，把該名隊員燒傷，之後也持續燃燒、波及靠近的人。[雷亞](../npcs/雷亞.md)頂著火焰衝上前，一記巨劍重擊加上至聖斬，**把殭屍劈成兩半**，劍身在命中時綻放出神聖的光芒。

### 銀劍與雪花球藥水

殭屍留下那把銀劍，隊伍把它的外觀改成刺劍，交給[奎恩](../characters/奎恩.md)。屍體的腰帶上有一個完好無損的小袋子，裡面是一小瓶從沒見過的**藥水**：瓶中有細小的冰霜像雪花球一樣旋轉。確認它不是毒藥後，交給[歐蓓](../characters/歐蓓.md)保管，之後再鑑定。

有隊員為屍體簡單禱告後，隊伍繼續上路，抵達了[大墓地](../places/大墓地.md)。

## 重要決定

1. 避開騎著夢魘的強大騎士，以救大公為優先。
2. 主動偷襲燃燒的殭屍。
3. 銀劍改成刺劍交給[奎恩](../characters/奎恩.md)；神秘藥水交給[歐蓓](../characters/歐蓓.md)保管。

## 劇情重點

- **夢魘騎士**：遠超隊伍實力的騎士在[艾爾托瑞爾](../places/艾爾托瑞爾.md)遊蕩，身分與目的不明。
- **燃燒的殭屍**：平時看似沒有燃燒，被靠近時會全身爆出火焰。牠手持鍍銀長劍、帶著魔法藥水，生前可能是冒險者或騎士。
