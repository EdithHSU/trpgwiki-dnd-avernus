# 姆普姆普

!!! abstract "本集概要"
    接續[水管與地下城](2025-05-24.md)的戰鬥。隊伍擊倒的敵人消失得只剩一套衣物，[奎恩](../characters/奎恩.md)便穿上它假扮[萬瑟姆普家](../npcs/萬瑟姆普家族.md)的人，帶著換上邪教徒長袍的隊友，在[萬瑟姆普宅](../places/萬瑟姆普宅.md)地下一路唬弄惡魔守衛。隊伍找到托姆的聖徽護手，最後在地牢救出兩名囚犯。

!!! note "劇情順序"
    這一集的錄音日期比[水管與地下城](2025-05-24.md)早，但劇情在它之後。網站依劇情順序排列。

## 劇情

### 只剩衣物的敵人

隊伍延續上一集的戰鬥，[雷亞](../npcs/雷亞.md)一度倒地，隊友以藥水與治療搶救。戰鬥尾聲，隊伍擊倒了目標，對方卻**沒有留下屍體，只留下一套衣物**便消失了。隊伍討論了這個人究竟是誰，以及要怎麼利用這套衣物。

### 喬裝成萬瑟姆普

隊伍決定由聲音表演能力最好的[奎恩](../characters/奎恩.md)穿上這套衣物，假扮[萬瑟姆普家族](../npcs/萬瑟姆普家族.md)的人，其餘隊員換上先前找到的邪教徒長袍與金色面具，分成前排與後排的隊形。

在通道上，一隻會飛的惡魔守衛一見到「萬瑟姆普」就立刻下跪，後面的邪教徒也跟著跪下。[奎恩](../characters/奎恩.md)順勢問話，得知牠們原本奉命前往廣場追捕「入侵者」。奎恩下令要牠們「把這裡的食物吃光」，把守衛與部分邪教徒支開了。

### 祭壇廳的法陣

隊伍回到祭壇大廳調查。天花板的壁畫描繪著一個高位階的惡魔，地板上刻著金色的法陣，看起來是用來與神明或使者溝通、預知未來的儀式場地，但儀式已經結束。隊伍決定**先不破壞**法陣。

### 托姆的聖徽護手

隊伍找到一間有十張床的信徒宿舍，以及一間裝飾華麗的私人房間。房裡掛著兩幅畫，一幅描繪靈魂墮化為低階惡魔的過程，另一幅是被鎖鏈捆綁的高階惡魔。箱子裡有一件**托姆聖徽造型的右手護手**，隊伍帶走了它。

### 一路唬弄到地牢

隊伍經過廚房、糧倉與酒窖，拿了些補給和幾瓶好酒，[嘴嘴](../npcs/嘴嘴.md)一路窩在[安格](../characters/安格.md)的肩上。途中兩度發現躲在木箱裡的小魔鬼，都以「萬瑟姆普」的身分把牠們打發走。

在通道中，隊伍撞見兩名真正的邪教徒。對方逐漸起疑，雙方爆發戰鬥，隊伍很快就擊倒了他們，把屍體藏進掛著獸屍的冷藏室。

### 地牢裡的囚犯

鐵欄門前有一隻像蛇的獄卒緊盯著隊伍，門後是關押囚犯的牢房。隊伍救出兩名囚犯：

- 一名五十多歲、衣衫不整的男性學者，被隊伍認出可能是一位研究邪教活動的知名學者，也就是之後同行到[燭堡](../places/燭堡.md)的學者**[福萊斯特](../npcs/福萊斯特.md)**。
- 一名七十多歲、氣質仍在的老婦人，身分當時沒能確認。後來隊伍得知，她出身原本保管[加格斯之盾](../items/加格斯之盾.md)的貴族胡恩家族。

本集結束時，隊伍還沒找到[至高監督者](../npcs/至高監督者.md)。

## 重要決定

1. 由[奎恩](../characters/奎恩.md)假扮[萬瑟姆普家](../npcs/萬瑟姆普家族.md)的人，其餘隊員喬裝成邪教徒滲透。
2. 暫不破壞祭壇廳的法陣。
3. 遇到惡魔守衛與小魔鬼時，優先唬弄、支開，不直接開戰。
4. 帶走地牢裡的兩名囚犯。

## 劇情重點

- **消失的敵人**：被擊倒的目標沒有留下屍體，只留下衣物。
- **托姆的線索**：托姆聖徽造型的護手，暗示[至高監督者](../npcs/至高監督者.md)與托姆信仰的關聯。
- **獲救的囚犯**：研究邪教的學者，以及出身貴族家族的老婦人。
