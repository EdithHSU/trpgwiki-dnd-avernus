# 大兒子裸奔

!!! abstract "本集概要"
    隊伍在[萬瑟姆普宅](../places/萬瑟姆普宅.md)二樓制伏[萬瑟姆普家](../npcs/萬瑟姆普家族.md)的大少爺，問出一面神秘盾牌與[至高監督者](../npcs/至高監督者.md)勾結[扎瑞爾](../npcs/扎瑞爾.md)的線索，[奎恩](../characters/奎恩.md)再讓他當眾裸奔到廣場。之後隊伍跟著魔法貓找到密門，在宅邸地下擊敗一名強大的女性頭目，發現邪教的據點。

## 劇情

### 二樓的搜索

隊伍繼續搜索深居簡出的公子瑟斯維爾的房間，翻出一套華貴的貴族服裝，卻觸發了衣物上的魔法機關。附近房間的一名法師守衛被迅速擊倒，隔壁則是一間擺滿模型的收藏室。

### 審問大少爺

隊伍制伏了[萬瑟姆普家族](../npcs/萬瑟姆普家族.md)的大少爺並加以審問，問出幾條重要線索：

- 有一面稀世的**隱藏領主之盾**，是某些組織正在尋找的目標，力量不明。這面盾牌後來落入[凱侖](../characters/凱侖.md)手中，也就是[加格斯之盾](../items/加格斯之盾.md)。
- [艾爾托瑞爾](../places/艾爾托瑞爾.md)的[至高監督者](../npcs/至高監督者.md)，似乎與[扎瑞爾](../npcs/扎瑞爾.md)的勢力有所勾結。
- [萬瑟姆普家族](../npcs/萬瑟姆普家族.md)內部對幾個兒子的評價差距很大，家族裡有明顯的偏心與矛盾。

### 大兒子裸奔

隊伍決定不殺他。[奎恩](../characters/奎恩.md)先用化妝品替他畫上紅鼻子，再對他施放**暗示術**，讓他以為自己「很熱」，接著鬆綁放人。大少爺當眾脫下衣物，朝廣場的方向裸奔而去，本集集名就是這一幕。

### 通往地下的密門

魔法貓[嘴嘴](../npcs/嘴嘴.md)帶著隊伍找到宅邸裡一道隱藏的石板密門，底下有木梯通往地下。

### 黑曜石祭壇的女頭目

隊伍沿著螺旋樓梯與長廊深入地下，來到一座以黑曜石堆砌的巨大祭壇大廳，祭壇上噴出**天使形狀的火焰**。一名身穿華貴禮服、灰白頭髮的女性原本跪地祈禱，轉身後與隊伍爆發戰鬥。她的魔法與近戰能力都很強，[雷亞](../npcs/雷亞.md)多次身受重傷，靠隊友輪番施藥治療才撐過去。

隊伍最後將她擊倒，她留下一句意味深長的話後化為灰燼消散，只留下兩把鑰匙，沒有留下屍體。

### 邪教的據點

祭壇上的魔法火焰帶有[扎瑞爾](../npcs/扎瑞爾.md)的意象，周圍刻著艱澀的符文。隊伍謹慎地沒有破壞祭壇，繼續探索，在一間更衣室找到七套教團長袍與金色的惡魔面具，確認這裡是邪教的據點。本集在隊伍即將撞見兩名戴面具的教徒時結束。

## 重要決定

1. 不殺大少爺，改讓他當眾裸奔，並取走他身上的財物與書籍。
2. 跟著魔法貓找到通往地下的密門。
3. 與地下的女性頭目正面交戰。
4. 不破壞祭壇，繼續探索周邊區域。

## 劇情重點

- **隱藏領主之盾**：第一次出現的神秘盾牌線索。
- **[至高監督者](../npcs/至高監督者.md)的陰謀**：[艾爾托瑞爾](../places/艾爾托瑞爾.md)的至高監督者可能與[扎瑞爾](../npcs/扎瑞爾.md)勾結。
- **宅邸地下的邪教**：黑曜石祭壇、天使形狀的火焰、教團長袍與面具，證實[萬瑟姆普宅](../places/萬瑟姆普宅.md)底下藏著一個活躍的邪教。
