# 半獸人小不點

!!! abstract "本集概要"
    隊伍進入[燭堡](../places/燭堡.md)，由[希爾維亞](../npcs/希爾維亞.md)解開謎盒，揭露[至高監督者](../npcs/至高監督者.md)與[扎瑞爾](../npcs/扎瑞爾.md)的契約。[雷亞](../npcs/雷亞.md)立誓奪回[艾爾托瑞爾](../places/艾爾托瑞爾.md)，[凱侖](../characters/凱侖.md)則阻止了對至高監督者的私刑。希爾維亞說出[盾牌](../items/加格斯之盾.md)的真面目，並安排隊伍經由[崔希哥](../npcs/崔希哥.md)前往[阿弗納斯](../places/阿弗納斯.md)。

## 劇情

### 進入燭堡

隊伍沿小徑抵達[燭堡](../places/燭堡.md)，三名身穿紫袍的僧侶前來迎接，說明進入燭堡必須獻上一本書或卷軸。隊伍獻上[萬瑟姆普家](../npcs/萬瑟姆普家族.md)大兒子親手寫的「多元宇宙末日預言」筆記，精靈僧侶翻閱後很驚喜，認為這是很好的禮物。同行的學者[福萊斯特](../npcs/福萊斯特.md)一進門就很興奮，想盡快拜訪能解開謎盒的學者。

### 謎盒裡的契約

隊伍在一座窗戶緊閉的圓塔實驗室找到[希爾維亞](../npcs/希爾維亞.md)：一名中年提夫林女學者，地板上畫著巨大的九芒星，桌角停著她的小惡魔。她多年前見過[至高監督者](../npcs/至高監督者.md)一面，直覺告訴她「他是個騙子」。

[希爾維亞](../npcs/希爾維亞.md)把一瓶黑色液體倒進盒面迷宮般的紋路，謎盒隨之旋轉裂開。盒中是一片以九條鎖鏈纏繞、刻著煉獄語符文的黑鐵板，記載著[至高監督者](../npcs/至高監督者.md)**塔維斯・克雷格**與[阿弗納斯](../places/阿弗納斯.md)之主**[扎瑞爾](../npcs/扎瑞爾.md)**的契約。大意是塔維斯侍奉扎瑞爾，換取能驅逐怪物的「伴陽」；代價是伴陽照耀下的土地，以及所有立誓守護[艾爾托瑞爾](../places/艾爾托瑞爾.md)的人，期限五十年。

[希爾維亞](../npcs/希爾維亞.md)表示，破解這類契約最常見的方法是**毀掉契約**，而不是殺死魔鬼。這片鐵板只是**副本**，正本應該藏在[扎瑞爾](../npcs/扎瑞爾.md)身邊更安全的地方。

### 差點當場處決至高監督者

一名隊員聽完契約後衝進[至高監督者](../npcs/至高監督者.md)的房間，直接揍了他一拳。至高監督者辯稱「托姆沒有回應我」，哭著說自己被魔鬼欺騙。

[雷亞](../npcs/雷亞.md)得知所有立誓的國民都是獻給[扎瑞爾](../npcs/扎瑞爾.md)的祭品，雙膝跪地、把臉埋進手裡。隨後她抬起含淚卻堅毅的臉說：「**我會去奪回[艾爾托瑞爾](../places/艾爾托瑞爾.md)。如果扎瑞爾想要我的靈魂，就讓她試試看。**」

[雷亞](../npcs/雷亞.md)說在那之前要先殺了這個雜種，一名隊員隨即拔出大劍要處決[至高監督者](../npcs/至高監督者.md)。此時[凱侖](../characters/凱侖.md)以靈體武器擋下，勸說：現在殺了他只是發洩怒氣，應該公開他的罪行，交給艾爾圖加德的人審判。雷亞最終同意。隊伍把證據交給[燭堡](../places/燭堡.md)中的地獄騎士，由凱侖將至高監督者移送法辦；[維提克](../characters/維提克.md)則寫信給一位倖免於難的地獄騎士將軍，說明真相。

### 酒館裡的半獸人小不點

酒館裡，一群得知真相的地獄騎士正借酒澆愁，[維提克](../characters/維提克.md)也在其中。角落有一名戴著金色頭帶、讀著神學著作的**半獸人**，身上帶著知識之神歐格瑪的聖徽。他自稱「**小不點**」：以前不懂事，殺了一個叫小不點的半身人、拿到這條讓他開了智慧的頭帶，從此不再殺生，並用對方的名字警惕自己。[奎恩](../characters/奎恩.md)向他打聽**死亡三神**的書籍，小不點神色慌張，但答應帶他去看資料。

### 盾牌的真面目

[希爾維亞](../npcs/希爾維亞.md)來到酒館，得知隊伍要前往[阿弗納斯](../places/阿弗納斯.md)後，提出幫忙：

- 她的巫師朋友[崔希哥](../npcs/崔希哥.md)欠她人情，可以把隊伍送過去；崔希哥那裡還有一位曾與魔鬼作戰的老朋友[露露](../npcs/露露.md)可以帶路。
- 她把[燭堡](../places/燭堡.md)唯一的**[阿弗納斯](../places/阿弗納斯.md)地圖**送給隊伍。繪者已經發瘋，地圖滿是混亂記號，而且是無法抄錄的魔法物品。

接著她說出[凱侖](../characters/凱侖.md)那面盾牌的來歷：這是[隱藏領主之盾](../items/加格斯之盾.md)，封印著一名自稱「隱藏領主」的魔鬼**加格斯**。她推測博德之門近來的腐敗，可能與這面盾影響周遭有關。凱侖表示在找到能妥善處理它的人之前，不會輕易交出盾牌，自己對伊爾馬特的信仰也不會動搖。

此時周遭聲音像被沉默術蓋住，加格斯開口說，如果隊伍真的去了九獄，他會當「忠實的顧問」。[凱侖](../characters/凱侖.md)回應：「你是想試圖腐化我吧。」

### 啟程

隊伍在[燭堡](../places/燭堡.md)停留約一天半，查閱九獄與[阿弗納斯](../places/阿弗納斯.md)的資料。[希爾維亞](../npcs/希爾維亞.md)介紹她的小惡魔名叫**耶洗別**。學者[福萊斯特](../npcs/福萊斯特.md)**留在燭堡**，[雷亞](../npcs/雷亞.md)隨隊同行。第三天早上，隊伍騎上獅鷲，朝西飛越大海，抵達一座浮在空中、沒有門窗的[法師塔](../npcs/崔希哥.md#法師塔)。

## 重要決定

1. 請[希爾維亞](../npcs/希爾維亞.md)解開謎盒，帶走契約副本。
2. **不當場處決[至高監督者](../npcs/至高監督者.md)**，改為移送法辦。
3. [雷亞](../npcs/雷亞.md)與隊伍決定**前往[阿弗納斯](../places/阿弗納斯.md)奪回[艾爾托瑞爾](../places/艾爾托瑞爾.md)**。
4. [凱侖](../characters/凱侖.md)拒絕把[加格斯之盾](../items/加格斯之盾.md)交給希爾維亞研究，決定自己保管。

## 劇情重點

- **真相揭曉**：[艾爾托瑞爾](../places/艾爾托瑞爾.md)墜入[阿弗納斯](../places/阿弗納斯.md)，是因為[至高監督者](../npcs/至高監督者.md)為了換取伴陽與[扎瑞爾](../npcs/扎瑞爾.md)簽下的契約。
- **正義與私刑**：[雷亞](../npcs/雷亞.md)想當場處決至高監督者，被[凱侖](../characters/凱侖.md)以「交由人民審判」勸阻。
- **與魔鬼同行**：隊伍現在有一位帶著魔鬼之盾的牧師、一位與小惡魔簽約的遊俠，以及一位巴爾之子。
