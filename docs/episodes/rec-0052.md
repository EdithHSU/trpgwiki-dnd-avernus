# 維提克之劍

!!! abstract "本集概要"
    [露露](../npcs/露露.md)回憶中的[艾德爾格蘭](../places/艾德爾格蘭.md)之戰到了最後關頭：[耶諾古](../npcs/耶諾古.md)幾乎壓垮整支隊伍，直到還是天使的**[扎瑞爾](../npcs/扎瑞爾.md)**降臨，與露露聯手把他趕進傳送門。扎瑞爾向每個人提出同一個問題：「站在我的立場，你願意不顧一切嗎？」回到[湧血城寨](../places/湧血城寨.md)後，[耶爾](../npcs/耶爾.md)的幽魂說出劍的最後一道試煉：拔劍的人將不再是原本的自己。[維提克](../characters/維提克.md)拔出了[扎瑞爾之劍](../items/扎瑞爾之劍.md)，化為天使。

!!! note "關於這段錄音"
    這一集是同一天團務的兩個錄音筆原檔（0052、0053），沒有集名，錄音日期不明。內容直接接續[露露的回憶：艾德爾格蘭](rec-0051.md)結尾的耶諾古之戰，角色為 12 級。[奎恩](../characters/奎恩.md)這一集沒有出場，和阿弗、詹德一起留在聖門外。

## 劇情

### 耶諾古的壓制

戰場上的小兵大多已經倒下，一隻巴古拉魔被放逐，[歐蓓](../characters/歐蓓.md)也把變成霸王龍的[蓋比](../characters/蓋比.md)變回原形。剩下的只有[耶諾古](../npcs/耶諾古.md)。

[凱侖](../characters/凱侖.md)展開**暮光聖域**，讓隊友每回合獲得臨時生命值。[維提克](../characters/維提克.md)身上還有歐蓓的高等隱形術，耶諾古看不見他；他全力揮砍，造成了全隊最大的傷害，武器上的光耀之力持續灼燒著耶諾古。[露露](../npcs/露露.md)衝上前，卻被連枷甩飛、倒在地上。

渾身浴血的耶諾古狂笑不止，像是終於遇上旗鼓相當的對手：

- 三顆連枷頭一起砸在[蓋比](../characters/蓋比.md)身上。
- [歐蓓](../characters/歐蓓.md)被擊中後陷入困惑，暫時無法自由行動。
- [安格](../characters/安格.md)被麻痺。
- 他還以傳奇動作一口接一口，咬遍身邊的每個人。

露露站起來後，雖然還在氣安格殺死平民的事，仍替他治療，卻只給了一點點：「**在你改邪歸正之前，你只能得到這麼多。**」維提克接下來的四次攻擊全部落空，耶諾古聽見武器劃過空氣的聲音，放聲大笑。

最後，耶諾古以連枷重擊被麻痺的安格，安格倒地、瀕臨死亡。歐蓓沒有治療的手段，改以五環的魔法飛彈攻擊耶諾古。耶諾古的氣勢眼看就要更上一層。

### 天使扎瑞爾

耶諾古忽然閉上嘴，瞇眼往上看。一道閃光劈開迷霧，一名天使降了下來：碧藍色的長髮、四隻散發白光的藍色翅膀，雙眼蒙著白布。同一時間，[露露](../npcs/露露.md)也發出光芒，變成一頭長著雙翼的巨大金色猛獁象。

天使的長劍刺穿耶諾古的胸膛，念出咒語，在他身後打開一道傳送門。露露感覺「就是現在」，衝上前用巨大的身軀與象牙把耶諾古撞進門裡，門隨即關上。露露對這位天使感到無比熟悉：她就是當年和自己一起轉戰各地的那個人。

天使蹲下觸碰倒地的[安格](../characters/安格.md)，治好他大部分的傷，然後說：「勇敢的戰士們，我是天使**[扎瑞爾](../npcs/扎瑞爾.md)**，感謝你們守護這個地方。」她的模樣，和教堂前的雕像幾乎一模一樣。

迷霧中出現一批穿著老式板甲、帶有艾爾圖加德與[艾爾托瑞爾](../places/艾爾托瑞爾.md)徽紋的騎士，開始掃蕩殘存的豺狼人、搜救傷者。一名臉上有深長傷疤、約三十歲的女騎士騎馬來到扎瑞爾身邊，向隊伍鞠躬致謝：她就是**[耶爾](../npcs/耶爾.md)**，[奧蘭蘇斯](../npcs/奧蘭蘇斯.md)日記裡深愛的人，也是隊伍在墓穴與城寨中見過的女騎士幻影。軍中還有年輕、意氣風發的[詹德](../npcs/詹德.md)、[哈魯曼](../npcs/哈魯曼.md)與奧蘭蘇斯。

### 扎瑞爾的問題

[維提克](../characters/維提克.md)上前說明，他們是「來自很久以後的旅人」，正在對抗難以抗衡的邪惡，需要她的劍。

這時[露露](../npcs/露露.md)想起了劍的來歷：她和扎瑞爾攻進阿弗納斯後，傳送門因地獄騎士的背叛被封死；扎瑞爾被抓之前把劍交給露露。露露和[耶爾](../npcs/耶爾.md)帶著劍逃亡，被耶諾古的巨型惡魔（就是[湧血城寨的聖門](rec-0050.md)那隻會吐出怪物的巨獸）緊追不放。快被追上時，耶爾把劍插進石頭，露露把自己的力量灌進石中，形成了這座聖所。

維提克問扎瑞爾，什麼樣的事會讓她放棄希望、轉向邪惡。扎瑞爾看著忙碌的騎士們回答：她與耶諾古對抗，是因為耶諾古殺了她立誓保護的人；也許為了阻止牠與其他邪惡，她將不得不拋棄自己象徵的一切。她反問：「**如果那能阻止深淵的混亂之潮、拯救許多生命，站在我的立場，你願意不顧一切嗎？**」

她向每個人都問了同樣的問題，並各給了一道護咒（**活力護咒**可移除力竭或治癒疾病、毒素；**復原護咒**可施展一次次等或高等復原術）：

- **[維提克](../characters/維提克.md)**：引用理髮師布妮對他說過的話：「你願意為願景犧牲到什麼程度？」他說自己也會不顧一切。扎瑞爾祝福他永遠走在光明的道路上，在他手臂畫下洛山達的聖徽，給了他活力護咒。
- **[歐蓓](../characters/歐蓓.md)**：說她們的時代有一位天使朋友，為了拯救更多人在阿弗納斯不停作戰，卻走得太遠、被阿弗納斯同化，問扎瑞爾會怎麼做。扎瑞爾的眉頭越皺越緊，回答：如果那位朋友心中還有一絲善念，就提醒她過去是什麼樣的人，她永遠可以選擇成為哪一個自己。歐蓓自己的答案是：她身為卓爾，從小被教導可以不擇手段，直到伊莉絲翠告訴她，人永遠有選擇，也永遠有悔改的機會。她得到活力護咒。
- **[露露](../npcs/露露.md)**：抱住扎瑞爾說「我一定會把妳帶回來」。扎瑞爾不明白她在說什麼，只是微笑著說「我們去哪裡都會一起」。
- **[凱侖](../characters/凱侖.md)**：拿出[加葛斯之盾](../items/加葛斯之盾.md)。扎瑞爾看出盾裡封著一個邪惡的魔鬼，而且她能把他放出來、當場消滅，問凱侖願不願意為了剷除邪惡捨棄自己的羈絆。凱侖猶豫後回答：他的初心是拯救善良的人，不完全等於剷除邪惡；來到地獄後，他也遇過願意善待他們、努力想變好的邪惡生物，讓他開始懷疑什麼是善、什麼是惡。扎瑞爾說這和她的經驗相差太多，無法給他建議，但洛山達仍會守護他的道路，給了他復原護咒。**凱侖沒有讓扎瑞爾放出加葛斯。**
- **[蓋比](../characters/蓋比.md)**：會不顧一切把敵人都消滅。她得到活力護咒。
- **[安格](../characters/安格.md)**：「我得跟妳老實說」，他會不顧一切拯救身邊重要的人，但不是所有人。他得到復原護咒。

一名隊員對安格說，扎瑞爾的墮落是一個過程，而不是結果，安格也一樣：原本的安格不排斥善良或邪惡的方法，現在卻只看得見邪惡的那一種。安格承認，他沒有想走回原本的樣子，邪惡的方法確實比較有效率。

維提克也找到了年輕的[詹德](../npcs/詹德.md)，激動地說：「雖然我們現在還不認識，但看到這樣的你，我非常高興。」他用力擁抱詹德，告訴他「很久以後的你也還在持續努力」。詹德微笑著說：「我希望我也是如此。」

扎瑞爾舉劍向隊伍致意，帶著部隊最後一個走進傳送門。

### 最後的試煉

強光過後，隊伍回到[湧血城寨](../places/湧血城寨.md)的大教堂。光線穿過血痂與彩繪玻璃，聖座上，那把劍依然插在石中；露露也變回了小象。

女騎士以白色幽魂的模樣出現在劍前，她就是[耶爾](../npcs/耶爾.md)。[露露](../npcs/露露.md)想起了一切：

- [艾德爾格蘭](../places/艾德爾格蘭.md)就是她們剛才救下的小鎮，也是這一切的導火線。
- 她跟著扎瑞爾來到阿弗納斯，但這裡的邪惡太強大。一名魔鬼向扎瑞爾現身，承諾派出地獄軍團助她終結這場血戰，條件是向阿斯莫蒂斯效忠。扎瑞爾答應了，成了魔鬼大公。
- 露露和耶爾帶走她的劍，希望有一天能讓扎瑞爾得到救贖；為了打造這座聖所，耶爾獻出了生命。

耶爾說，隊伍已經通過了許多試煉，但還剩最後一關。她指向劍旁的天界語碑文，大意是：**與此劍合而為一的人，其存在也將消失。**拔劍的人會轉化為天使，陣營變為守序善良，性格也會隨之改變：絕不說謊、尊重所有人包括敵人，也可能為了更大的利益犧牲無辜的人。

隊伍討論由誰拔劍：[詹德](../npcs/詹德.md)很適合，但他在門外，轉化後也不再是原本的詹德；露露該留著去救扎瑞爾；[奎恩](../characters/奎恩.md)已經和魔鬼簽約。最後，[維提克](../characters/維提克.md)決定由自己來。

- **[歐蓓](../characters/歐蓓.md)**問他有沒有話要託付。維提克請她若遇到他的父母，替他道謝並道歉；也請她轉告詹德，過去的他說會一直努力走在正確的路上。歐蓓尊重他的決定，擁抱了所有人，答應會把伴陽掛回天上。
- **[安格](../characters/安格.md)**老實說不贊成：「我只保護我在乎的人」，一定還有其他辦法，而維提克就是他在乎的人。維提克最後一次問安格要不要變回善良，因為這可能是他以自己的意志使用托姆恩賜的最後機會；安格回答，他願意用現在的樣子繼續和大家一起戰鬥。維提克接受了，也請隊友轉告[雷亞](../npcs/雷亞.md)：他做的一切都是為了地獄騎士的使命。
- **[凱侖](../characters/凱侖.md)**問：「你確定你不會成為第二個扎瑞爾嗎？」維提克回答：「我相信你們會阻止我。」

維提克也到聖門外，向[詹德](../npcs/詹德.md)、[奎恩](../characters/奎恩.md)與[阿弗](../npcs/阿弗.md)說明。奎恩不太理解，但覺得很偉大，說要寫一首詩歌記下這件事；阿弗想知道拔劍、轉化與正義是什麼感覺，請維提克之後告訴他。維提克單獨告訴詹德，他在回憶裡見到了過去的詹德；詹德說，自己在哈魯曼之丘看到同僚的模樣後失去了希望，但和隊伍相遇後，又想起了與扎瑞爾並肩作戰的感覺。耶爾為三人打開聖門，讓他們進來觀看。

### 維提克之劍

劍以從未見過的金屬打造，靠近時嗡嗡作響。[維提克](../characters/維提克.md)深吸一口氣，環視所有人，握住劍柄往上提。劍劇烈震動，想掙脫他的手；他把自己的魔力注入劍中與之抗衡，最後劍安靜地停在他手上。拔劍前的擔心與恐懼，全都消失了。

維提克的雙眼轉為明亮的銀色，頭髮變得非常淺，全身散發神聖的微光，背後展開一對美麗的羽翼。他的職業不變，但：

- 魅力大幅提升，對光耀與死靈傷害有抗性。
- 雙眼能看穿魔法黑暗、看見隱形的事物與以太位面。
- 持劍時，察覺與洞察都更加敏銳。

劍是有智能的武器，能造成光耀傷害。它以高亢的少年嗓音在維提克腦中說：「繼承扎瑞爾的是你嗎？我一直被稱為扎瑞爾之劍，那從現在開始，我就是**維提克之劍**。」

本集在這裡結束。

## 重要決定

1. [凱侖](../characters/凱侖.md)拒絕讓扎瑞爾放出並消滅[加葛斯](../items/加葛斯之盾.md)。
2. [露露](../npcs/露露.md)仍替[安格](../characters/安格.md)治療，但刻意只給最少的量。
3. 隊伍沒有直接告訴年輕的扎瑞爾她將來會墮落，只用「天使朋友」的說法旁敲側擊。
4. 安格再次拒絕以托姆的恩賜回到善良。
5. **[維提克](../characters/維提克.md)拔出[扎瑞爾之劍](../items/扎瑞爾之劍.md)**，轉化為天使。

## 劇情重點

- **扎瑞爾墮落的真相**：她為了守護被耶諾古屠殺的人而戰，接受了以向阿斯莫蒂斯效忠換取地獄軍團的條件，成為魔鬼大公。她問每個人的那個問題，本身就預示了她的墮落。
- **每個人的回答**：維提克會不顧一切、歐蓓相信永遠能悔改、凱侖懷疑善惡的界線、蓋比會消滅所有敵人、安格只救身邊重要的人，幾乎就是每個人現在的樣子。
- **[扎瑞爾之劍](../items/扎瑞爾之劍.md)的來歷**：耶爾把劍插進石中、露露灌注力量，耶爾獻出生命，建成這座聖所。
- **[耶爾](../npcs/耶爾.md)**：以生前與幽魂兩種樣貌登場。阿弗進不了聖門，沒能替奧蘭蘇斯把話帶到。
- **[露露](../npcs/露露.md)與[安格](../characters/安格.md)**：露露把治療的多寡和安格的善惡掛鉤，兩人的關係持續惡化。
- **維提克之劍**：維提克成為天使，劍有了新的名字與自己的意志。
