# 血痂裡的城寨

!!! abstract "本集概要"
    獲得自由的[柯斯徹齊](../npcs/柯斯徹齊.md)化成雲霧飛走，發誓要拿回戰鎚、打爛扎瑞爾。長休時，[歐蓓](../characters/歐蓓.md)發現[加格斯](../items/加格斯之盾.md)在教小魔鬼吞噬靈魂，促成全隊第一次公開討論這面盾牌，[凱侖](../characters/凱侖.md)也坦白了自己對加格斯的承諾。隊伍爬上包住[湧血城寨](../places/湧血城寨.md)的巨大血痂，從惡魔挖出的洞進入城寨，打退了一大群地獄蒼蠅。

!!! note "關於這段錄音"
    這是錄音筆的原始檔，沒有集名，錄音日期不明。內容直接接續[奧蘭蘇斯的日記](monkie-4.md)，角色在本集長休後升到 11 級。

## 劇情

### 放走巨人

鏈魔倒下時，[柯斯徹齊](../npcs/柯斯徹齊.md)大吼一聲。他的戰鎚在扎瑞爾手上，他講了一串隊伍聽不懂的巨人語，沒有仔細看隊伍一眼，就化成一團雲霧穿過眾人身邊。一名隊員讀了他的心，聽見清楚的念頭：「**我要拿回我的戰鎚，用我的鎚子打爛扎瑞爾。**」隊伍覺得他目標明確，便讓他離開。

傳送拱門只會在身後開十分鐘，已經來不及了。隊伍決定**就地長休**，再慢慢爬出約 500 尺深的坑。

### 歐蓓與小魔鬼

長休時，[安格](../characters/安格.md)的小魔鬼跑來問[歐蓓](../characters/歐蓓.md)，能不能再把牠變成恐龍。牠說自己**吃了兩個靈魂**，覺得身體變強了；盾牌終於跟牠說話了，「他現在是我的老師」。

歐蓓說她理解這是魔鬼的本性，但因為[蓋比](../characters/蓋比.md)對魔鬼有創傷，請牠**只吃魔鬼和惡魔，千萬不要吃人類**，不管盾牌說什麼，也要牠先去告訴安格。小魔鬼答應了。

### 歐蓓與凱侖的夜談

歐蓓把這件事告訴[凱侖](../characters/凱侖.md)。凱侖敲敲盾牌質問，加格斯回答：「如果有人肚子餓了，你叫他去吃東西，那能算是慫恿嗎？」

兩人討論要不要銷毀盾牌。凱侖認為沒有安全的方法，貿然毀掉反而會放出麻煩；而且在加格斯真正作惡之前，凱侖沒有立場定罪。兩人約定**彼此觀察、互相提醒**，不讓任何人在邪惡的路上走太遠。

凱侖坦白：**答應過加格斯，若他在這趟旅程中幫忙拯救艾爾托瑞爾的人，就放他出來**。歐蓓基本上同意，但希望這是全隊一起做的決定，也要讓大家知道盾牌會說話，避免有人私下與它交易。凱侖答應隔天早餐時向大家坦白。

### 早餐時的坦白

[凱侖](../characters/凱侖.md)向全隊說明：盾牌裡有個不懷好意的存在，一路上不斷和凱侖溝通，大家看過的火球就是它放的；凱侖也說出了對加格斯的承諾。

- 歐蓓提出底線：小魔鬼只吃阿弗納斯原生的生物，不吃類人生物。[安格](../characters/安格.md)說自己會看好小魔鬼，但若有人對牠出手，他也會反擊：「牠是我的所有物。」
- 安格也坦承**跟盾牌說過話**，盾牌教了他使用穢液的方法，他只會在束手無策時使用。
- [維提克](../characters/維提克.md)向凱侖借盾牌，和加格斯有一段不太愉快的對話，之後提醒大家加格斯非常擅長操弄人心。
- [蓋比](../characters/蓋比.md)全程沉默，臉色很難看。

早餐後，小魔鬼問歐蓓為什麼人類討厭牠。歐蓓說，魔鬼的生存方式大多會傷害人類；但牠現在是隊伍的一員，露露也接納了牠，牠也有走上善良道路的可能。

### 湧血城寨

隊伍爬出深坑，朝[湧血城寨](../places/湧血城寨.md)前進。在一片冒泡的血泥沼澤中，眼前是一座山丘般的巨大**血痂**：約 300 尺高，白色聖殿的半圓穹頂從頂端破殼而出，纏著漆黑的鐵鏈。[露露](../npcs/露露.md)想起來了：整座城堡被埋在血痂裡，**正門在最深處的底部**，血痂靠近頂端的地方有個洞可以爬進去。

隊伍沿著鐵鏈往上爬。兩名隊員在約三分之一的高度摔了下來，歐蓓開了一道門把他們送上頂端。隊伍身上幾乎沒有治療藥水了。

### 彩繪玻璃窗

頂端的洞是中型生物用爪子硬挖出來的，大概是惡魔想來偷東西。往下走，有一扇被挖出來的**彩繪玻璃窗**，畫著一位在默禱的美麗天使。

[維提克](../characters/維提克.md)用大劍敲窗，窗戶沒壞，一股能量反而流進他體內，給了他一層保護。這份祝福**只給善良的人**：其他善良的隊員也都得到了，小魔鬼摸了卻什麼也沒感覺到。露露推測這裡仍是神聖的場所。

小魔鬼說，牠覺得善良很好，但也不討厭現在邪惡的自己。歐蓓勸牠「評估哪一條路對自己更有利再做選擇」，團員吐槽善良好像不是這樣選的。

### 地獄蒼蠅

隊伍往下爬到一個洞穴，聽見嗡嗡的振翅聲：一大群**地獄蒼蠅**正在啃食滿地的惡魔屍體。

- 一名隊員替維提克施放高等隱形術，蒼蠅找不到他，全部圍攻[凱侖](../characters/凱侖.md)，鑽進盔甲裡。
- [奎恩](../characters/奎恩.md)在凱侖面前施放匕首之雲，[阿弗](../npcs/阿弗.md)噴出劇毒孢子，[詹德](../npcs/詹德.md)殺死一群，露露的聖光又打掉大半。
- 最後，凱侖透過[加格斯之盾](../items/加格斯之盾.md)放出火球，把剩下的蒼蠅全部燒成焦炭。

加格斯在一旁說，自己「可是很願意幫助艾爾托瑞爾」。本集在這裡結束。

## 重要決定

1. 讓化成雲霧的柯斯徹齊離開，讓他去找扎瑞爾。
2. 全隊公開加格斯之盾會說話的事，以及凱侖「幫忙拯救艾爾托瑞爾就放出加格斯」的承諾。
3. 小魔鬼只吃阿弗納斯原生的生物、不吃類人生物，由安格負責看管。
4. 從血痂外側攀爬，經頂端的洞進入湧血城寨，往下尋找正門。

## 劇情重點

- **柯斯徹齊的誓言**：他要拿回戰鎚，打爛扎瑞爾。
- **加格斯的蠱惑曝光**：加格斯同時接觸了凱侖、安格與小魔鬼，全隊第一次公開討論這面盾牌。
- **安格與蓋比的對立**：安格說小魔鬼是他的所有物，誰動牠他就反擊；蓋比一言不發。
- **湧血城寨**：被巨大血痂包住，只能從惡魔挖出的洞進入；彩繪玻璃窗的祝福只給善良的人。
