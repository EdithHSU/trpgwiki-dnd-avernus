待確認名詞

墜入阿弗納斯 Wiki 整理時，從語音辨識逐字稿推測、還沒確定的名字與細節。

開始填寫

輸入你的名字和通關密語。名字可以用角色名或暱稱；名字一樣就算同一個人，答案會合併在一起，換手機或電腦時輸入同一個名字就能接著填。

怎麼填
  1. 知道正確答案就直接填；網站目前的寫法正確，按「目前寫法正確」。
  2. 點「辨識到的寫法」可以把它帶進輸入框再修改。
  3. 不記得就按「不確定」，或直接跳過。
  4. 答案會自動存到共用的答案表，每題下方會列出其他人填的答案；填到一半關掉也沒關係，下次打開會接著填。
