# 耶爾

!!! info ""
    扎瑞爾最忠誠的地獄騎士與副將，把[扎瑞爾之劍](../items/扎瑞爾之劍.md)藏起來的將軍。生死不明。

## 身分

扎瑞爾被俘之前，吩咐[露露](露露.md)把劍藏起來。耶爾帶著劍逃跑，把劍插進石頭裡，露露則在劍的周圍升起護盾。露露後來忘了是誰幫了她，直到[奧蘭蘇斯](奧蘭蘇斯.md)的日記揭露了耶爾的名字。

奧蘭蘇斯非常尊敬耶爾，而且深愛著她，卻從沒說出口。[阿弗](阿弗.md)答應，如果遇到耶爾，會替奧蘭蘇斯告訴她：曾經有個男人非常深愛她。

## 經歷

- [思考魔生的阿弗](../episodes/2025-10-25.md)：托姆之盔的幻象中，露露想起耶爾與保護劍的堡壘。
- [奧蘭蘇斯的日記](../episodes/monkie-4.md)：日記揭露藏劍的將軍就是耶爾，以及奧蘭蘇斯對她的愛。
