# 殘忍的阿克漢

!!! info ""
    紅色龍裔，提亞瑪特的信徒，脖子上戴著提亞瑪特之血。左手是會自行脈動的「維克那之手」。痛恨扎瑞爾。

## 身分

阿克漢住在[阿克漢之塔](../places/阿克漢之塔.md)，在山腰一顆巨大龍頭骨裡的營地進行儀式。提亞瑪特被九獄之主阿斯莫蒂斯打敗、囚禁在阿弗納斯，阿克漢願意為了讓「女王」出獄犧牲一切。他粗魯、喜怒形於色，強大到隊伍判斷打不贏。身邊有提亞瑪特的死亡牧師、龜人**克魯爾**，以及開著雙輪戰車的牛頭人**托羅加**。

他的綠色枯槁左手是**維克那之手**，渴望鮮血，連接處的血管像在往他的上臂爬行；他說這是到外界遊歷時得到的。

## 龍語石板契約

阿克漢以一整瓶提亞瑪特之血，換得龍珠寶珠與以下約定：簽名者得知扎瑞爾的動向或所在處時要通知他；要殺死扎瑞爾時，必須先通知他並等他到場；違約時，他會立刻取得所有簽名者身上價值超過 50 金幣的物品。
