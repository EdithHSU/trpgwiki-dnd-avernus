# 奧術魔

!!! info ""
    [貝爾](貝爾.md)手下的胡狼頭邪魔**緋熾泰特**，戴著小眼鏡、穿得像學者，是強大的施法者。受貝爾之命跟著隊伍尋找[精金權杖](../items/精金權杖.md)。

## 身分

奧術魔原本負責替貝爾拷問一隻收集情報的惡魔，習慣用拷問問話，被問到時還驚訝地反問「不然呢？」。他收了隊伍兩枚靈魂幣，就放走了那隻惡魔，結果惡魔反咬一口，他只好參戰，施放了死亡一指。

他對伴陽墜不墜落毫不在意，對隊伍的善心也常冷眼旁觀。

## 經歷

- [貝爾的委託](../episodes/rec-0041.md)：收下兩枚靈魂幣放走被拷問的惡魔，之後與隊伍一起把它擊倒。
- [奧術魔的煩惱](../episodes/rec-0042.md)：煩惱要怎麼向貝爾交代，被隊伍說服；透露權杖與伴陽是一套的。
- [松江南京站](../episodes/songjiang.md)：在旁觀看死者交談術，之後被說服留下來，一起尋找權杖。
- [艦橋上的冥想](../episodes/rec-0044.md)：質疑凱侖把法術用在無關的人身上；怪物現身時一彈指就消失了。
- [九根權杖](../episodes/rec-0045.md)：決定背著貝爾跟隨隊伍，開價要維提克的小指，換伴陽的秘密。
- [飛車追逐](../episodes/rec-0046.md)：一有戰鬥就躲開。
- [奧蘭蘇斯的日記](../episodes/monkie-4.md)：對拜訪柯斯徹齊非常興奮，以強大的法術轟擊鏈魔。
