# 嘴嘴

!!! info ""
    會說話的魔法貓。在[萬瑟姆普宅](../places/萬瑟姆普宅.md)被隊伍發現後一路跟著隊伍，目前暫時留在[崔希哥](崔希哥.md)的法師塔。

## 身分

隊伍第一次見到嘴嘴時，牠嘴裡叼著老鼠、一動也不動，看起來像蠟像擺飾，後來才發現牠會說話，還會分享自己的所見所聞。嘴嘴對萬瑟姆普宅的內部相當熟悉，和隊伍維持著「餵食換取合作」的關係。牠和小惡魔互相敵視。

## 經歷

- [造訪萬瑟姆普宅](../episodes/2025-04-12.md)：在深居簡出的公子房裡被隊伍發現。
- [大兒子裸奔](../episodes/2025-04-26.md)：帶隊伍找到通往地下的密門。
- [姆普姆普](../episodes/2025-05-17.md)：被餵食乾肉，一路窩在[安格](../characters/安格.md)的肩上。
- [要進入第二章囉](../episodes/2025-06-14.md)：在小惡魔找上安格時邊睡邊偷看。
- [半獸人小不點](../episodes/2025-06-28.md)：一直盯著小惡魔，也跑去騷擾[希爾維亞](希爾維亞.md)的小惡魔耶洗別。
- [歡迎來到埃爾圖迦德](../episodes/2025-07-12.md)：因為傳送人數有限，留在崔希哥的法師塔。
