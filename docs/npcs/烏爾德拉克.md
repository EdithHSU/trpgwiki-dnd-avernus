# 烏爾德拉克

!!! info ""
    來自天界的至高天巨人，受神的旨意前來消滅提亞瑪特，失敗後被提亞瑪特詛咒成鏈魔，在阿弗納斯困了上千年。喝下提亞瑪特之血恢復原狀後，離開了阿弗納斯。

## 身分

烏爾德拉克住在一頂埋在灰燼中的巨大巨人頭盔裡，身旁是一把劍柄嵌著**龍珠寶珠**的巨劍。他常自言自語，像在跟另一個人說話。要恢復原狀，他需要親手取得提亞瑪特的血，而那瓶血在提亞瑪特的信徒[殘忍的阿克漢](殘忍的阿克漢.md)身上。他的處境和同樣被困在阿弗納斯的天界存在扎瑞爾很像。

## 經歷

- [黃鷺鷥唱歌](../episodes/2026-01.md)：把龍珠寶珠交給隊伍，被[奎恩](../characters/奎恩.md)說服同行；他說自己在這裡等了幾千年，等的就是這一刻。
- [殘忍的阿克漢](../episodes/rec-0038.md)：怕被阿克漢認出，留在遠處；看到提亞瑪特之血時落下淚來，在大哥布林的伏擊中捏碎瓶子，開始變回至高天巨人。
- [苦痛之息的審判](../episodes/rec-0039.md)：恢復 25 尺高的至高天巨人真身；被[維提克](../characters/維提克.md)恢復善良，留下一加侖巨人之血，帶著[月色](月色.md)以異界傳送離開。
