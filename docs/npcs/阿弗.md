# 阿弗

!!! info ""
    對殺戮感到迷惘、想尋找存在意義的佛洛摩（鳥頭、有翼的惡魔）。名字取自「阿弗納斯的阿弗」。最信任[奎恩](../characters/奎恩.md)。

## 身分

阿弗原本跟著大批惡魔闖進艾爾托瑞爾，卻不明白同伴為什麼聽到人類尖叫就很開心。牠答應隊伍會克制本能、不隨意殺戮，之後接受了托姆的祈禱，開始思考「正義要做什麼」。阿弗會用刺耳的震懾尖嘯與劇毒孢子作戰，總是覺得新的體驗「很有趣」。
