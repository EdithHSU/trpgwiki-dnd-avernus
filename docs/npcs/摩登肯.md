# 摩登肯

!!! info ""
    住在[阿弗納斯](../places/阿弗納斯.md)的大法師，在這裡研究九獄如何影響魔法。領導冒險者組織「八環議會」，許多法術都以他的名字命名。

## 身分

摩登肯是一名年紀很大的人類，光頭、留著修剪整齊的鬍子、眼神銳利。他的鐵塔會跟著他移動，隊伍找到時，塔立在一座沸血湖的湖心小島上，外圍有麥哲羅斯魔看守，唯一的門開在高處的露台。

他不是好相處的人，只以魔法做出的分身見客。他對阿弗納斯的政治與艾爾托瑞爾的命運都沒有興趣，認為「宇宙有自己的平衡」。

## 經歷

- [沸血湖的摩登肯](../episodes/rec-0048.md)：從湖中現身，說伴陽裡「大概是某個天界生物」；簽名送給隊伍一本自己的書，叫隊伍去找方尖碑的法師。
