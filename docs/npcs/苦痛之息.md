# 苦痛之息

!!! info ""
    [阿弗納斯](../places/阿弗納斯.md)的軍閥，懸賞板上的名字。一隻沒有翅膀、嘴裡不斷冒出白煙的角魔，只能以心靈感應說話。

## 身分

苦痛之息本名**萊澤斯**，原本是[貝爾](貝爾.md)的部下，曾和貝爾一起對抗[扎瑞爾](扎瑞爾.md)。扎瑞爾統治阿弗納斯後，兩人密謀推翻她，但內部出了間諜。扎瑞爾把他降級成角魔、拔掉翅膀，並詛咒他**不能說話，也不能簽訂契約**。

他和大哥布林暴走族合作，因為想在這片土地上生存，就得有軍隊。他說貝爾早就不把他放在眼裡，而扎瑞爾不殺叛徒，是因為「有時候，活著比死更痛苦」。
