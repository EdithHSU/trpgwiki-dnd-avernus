# 柯斯徹齊

!!! info ""
    惡魔領主，別名「憤怒王子」。外形是巨人，被部分崇拜惡魔的巨人奉為神。曾敗給扎瑞爾，戰鎚被她奪走。

## 身分

柯斯徹齊肌肉發達、駝背、腿短、光頭、臉扁平，皮膚是病態的黃色。他沉迷戰鬥、殘暴跋扈，脾氣很差，而且極度厭惡女性，無法交涉。

他被扎瑞爾鎖在一個約 50 層樓深的坑底，泡在漆黑的瀝青池裡，由鏈魔與地獄獵犬看守。他的魔法戰鎚還在扎瑞爾手上。

[奧蘭蘇斯](奧蘭蘇斯.md)建議隊伍放他出來：他不會感謝隊伍，但會把注意力全放在扎瑞爾身上，正好拿來牽制她。

## 經歷

- [奧蘭蘇斯的日記](../episodes/monkie-4.md)：隊伍下到深坑，擊倒看守的鏈魔，鎖鏈鬆開，他獲得自由。
- [血痂裡的城寨](../episodes/rec-0049.md)：化成雲霧飛走，發誓要拿回戰鎚、打爛扎瑞爾。
