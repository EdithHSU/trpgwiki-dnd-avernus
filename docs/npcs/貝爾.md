# 貝爾

!!! info ""
    在扎瑞爾之前統治阿弗納斯的九獄大公，是扎瑞爾的敵人。

## 身分

[露露](露露.md)認為，貝爾既是扎瑞爾的敵人，也許很清楚湧血城寨的位置。她想到貝爾就打冷顫，提醒隊伍他不像拉爾薩拉或鬼婆那麼好說話。[拉爾薩拉](拉爾薩拉.md)願意寫介紹信讓隊伍去見他。

貝爾是一隻紅皮膚、大翅膀、形似龍人的**深獄煉魔**，腰間掛著頭顱。他在火山坡上的[貝爾的熔爐](../places/貝爾的熔爐.md)坐著飛行王座，監督戴著鐐銬的巨人打造武器。他和扎瑞爾互看不順眼，卻自稱現在仍是扎瑞爾「忠誠的參謀」；據說兩人正暗中進行軍備競賽。

他測試過隊伍的實力後，委託隊伍找回曾屬於扎瑞爾、與伴陽有關的[精金權杖](../items/精金權杖.md)，並派了手下的[奧術魔](奧術魔.md)跟著隊伍。被扎瑞爾降級的軍閥[苦痛之息](苦痛之息.md)，原本也是他的部下。

## 經歷

- [滅魔器與獨角獸](../episodes/monkie-2.md)：拉爾薩拉建議隊伍找貝爾推翻扎瑞爾。
- [黃鷺鷥唱歌](../episodes/2026-01.md)：露露決定為了找到扎瑞爾之劍，冒險去見貝爾。
- [苦痛之息的審判](../episodes/rec-0039.md)：苦痛之息說自己原本是貝爾的部下；籠中的尤格洛斯魔巴茲特也曾替貝爾做事。
- [羅剎之歌](../episodes/rec-0040.md)：在熔爐見到隊伍，自稱仍是扎瑞爾「忠誠的參謀」，拒絕直接回答湧血城寨的位置。
- [貝爾的委託](../episodes/rec-0041.md)：測試完隊伍的實力後送出惡魔護甲，委託隊伍找回[精金權杖](../items/精金權杖.md)。
- [奧術魔的煩惱](../episodes/rec-0042.md)：奧術魔煩惱該怎麼向貝爾交代被拷問的惡魔之死。
- [松江南京站](../episodes/songjiang.md)：隊伍依貝爾的委託，前往墜毀的飛行堡壘尋找權杖。
- [九根權杖](../episodes/rec-0045.md)：隊伍決定不把權杖交給他。
- [伊爾馬特的紅繩](../episodes/rec-0047.md)：加葛斯說貝爾能解放他。
