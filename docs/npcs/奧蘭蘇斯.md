# 奧蘭蘇斯

!!! info ""
    扎瑞爾聖戰時的地獄騎士將軍。不願服從墮落的扎瑞爾而自盡，卻被扎瑞爾喚醒成死亡騎士，守在[地獄騎士之墓](../places/地獄騎士之墓.md)。

## 身分

奧蘭蘇斯身穿古老的地獄騎士鎧甲，駕著兩頭石化牛拉的戰車，能召出同時帶著火焰與死亡力量的地獄火球。他在墓穴的暗室裡留下八本日記：

- 他責怪自己沒有看出扎瑞爾墮落的徵兆：她一心只想殺戮惡魔，不惜任何代價。
- 他形容戰友[哈魯曼](哈魯曼.md)冷酷無情、毫無同情心。
- 他深愛著把扎瑞爾之劍藏起來的將軍[耶爾](耶爾.md)，卻從沒說出口。

他對自己造成的傷害毫無歉意，認為那是戰鬥必經的過程；但確認隊伍的立場後，他協助隊伍解放了被困在墓中的騎士亡魂，並提出解放[柯斯徹齊](柯斯徹齊.md)來牽制扎瑞爾的計畫。

## 經歷

- [地獄騎士之墓](../episodes/monkie-3.md)：幽靈騎士說出他的遭遇；他駕著戰車穿牆而出，要隊伍「證明給我看」，被維提克重創後說「我可以考慮幫助你」。
- [奧蘭蘇斯的日記](../episodes/monkie-4.md)：說明剛才是在考驗隊伍；帶隊伍敲去石碑上的名字，向維提克行騎士禮後消失。
- [維提克之劍](../episodes/rec-0052.md)：年輕時的他出現在扎瑞爾軍中；阿弗進不了聖門，沒能替他向耶爾傳話。
