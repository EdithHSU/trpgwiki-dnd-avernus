# 拉爾薩拉

!!! info ""
    與扎瑞爾有契約的存在，曾囚禁[獨角獸月色](月色.md)。與隊伍立約：隊伍幫他解除與扎瑞爾的契約，他寫介紹信讓隊伍去見[貝爾](貝爾.md)。

## 約定

拉爾薩拉是阿弗納斯的一種邪惡元素生物，皮膚像泥土捏成，眼睛發光。他奉扎瑞爾之命守護囚禁[月色](月色.md)的「滅魔器」，但被困在那裡太多年，已經後悔替扎瑞爾做事。隊伍要破壞裝置時，他答應視而不見，條件是隊伍幫他打破與扎瑞爾的契約；他也介紹隊伍去找骨脊林的鬼婆[紅露絲](紅露絲.md)，並寫下讓隊伍去見貝爾的介紹信。

鬼婆說，要擺脫與扎瑞爾的契約，拉爾薩拉必須喝下**巨人之血**；在阿弗納斯能提供的，是被詛咒成鏈魔的巨人[烏爾德拉克](烏爾德拉克.md)。

烏爾德拉克恢復原狀後，留給隊伍一加侖的至高天巨人之血。拉爾薩拉只喝了一點就解除了契約，依約以煉獄語在石板上寫下給貝爾的介紹信，兩方就此兩清。
