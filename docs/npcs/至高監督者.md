# 至高監督者

!!! info ""
    [艾爾托瑞爾](../places/艾爾托瑞爾.md)的統治者**塔維斯・克雷格**。為了換取伴陽，與扎瑞爾簽下了出賣整座城市的契約。

## 身分

塔維斯原本是托姆的牧師。當年艾爾托瑞爾飽受吸血鬼等怪物侵擾，他以托姆牧師的身分召喚了**伴陽**，之後才成為至高監督者。

## 契約

[燭堡](../places/燭堡.md)的學者[希爾維亞](希爾維亞.md)解開的謎盒中，是他與扎瑞爾簽下的契約副本：他侍奉扎瑞爾，換取能驅逐怪物的伴陽；代價是伴陽照耀下的土地，以及所有立誓守護艾爾托瑞爾的人，期限五十年，之後艾爾托瑞爾及其守護者將「回到其來處」，一切依扎瑞爾所願。

被揭穿後，他哭著辯稱「托姆沒有回應我」，說自己被魔鬼欺騙了。

## 經歷

- [大兒子裸奔](../episodes/2025-04-26.md)：隊伍從萬瑟姆普家大少爺口中，得知至高監督者似乎與扎瑞爾的勢力有所勾結。
- [姆普姆普](../episodes/2025-05-17.md)：隊伍在萬瑟姆普宅地下找到托姆聖徽造型的護手，但還沒找到至高監督者本人。
- [要進入第二章囉](../episodes/2025-06-14.md)：由隊伍押送前往燭堡。
- [半獸人小不點](../episodes/2025-06-28.md)：契約內容被揭露，差點被[雷亞](雷亞.md)與[維提克](../characters/維提克.md)當場處決，[凱侖](../characters/凱侖.md)主張交由人民審判，最後被移送法辦。
