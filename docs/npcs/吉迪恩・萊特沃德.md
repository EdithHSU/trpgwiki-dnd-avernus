# 吉迪恩・萊特沃德

!!! info ""
    [大墓地](../places/大墓地.md)教堂的祭司，地獄騎士團的代表，[維提克](../characters/維提克.md)與[雷亞](雷亞.md)過去的上司。如今借用「其他的力量」。

## 身分

吉迪恩過去是虔誠正向的祭司。隊伍在大墓地再次見到他時，他穿著類似僧侶的輕裝，渾身散發邪惡氣息，指揮著兩隻麥哲羅斯魔，還能只用凝視殺死敵人。他說自己沒有拋棄信仰，但現在借用的是其他的力量，目的是與惡魔和魔鬼戰鬥、幫助艾爾托瑞爾的人民。

## 經歷

- [你做了什麼（2）](../episodes/2025-09-07-2.md)：在聖器室與隊伍並肩擊退惡魔，用凝視殺死巨蠍。
- [磨人的夸賽魔，看你往哪跑](../episodes/2025-09-14.md)：被隊伍認出身分，派麥哲羅斯魔「小麥」帶路；之後想消滅神智不清的[雷文加德大公](雷文加德大公.md)，被隊伍說服才讓步，但警告若大公與惡魔有關，他會追到天涯海角。
