# 馬哈迪

!!! info ""
    [流浪市集](../places/流浪市集.md)的主人，經營高級餐飲與水療店「煉獄飛昇」。外表是人類男性，卻不肯透露真實種族。[露露](露露.md)的舊識。

## 身分

馬哈迪熱情、優雅又精明，自稱受九獄之主阿斯莫蒂斯庇護。當年露露迷路流浪到市集，是他讓露露休息了一段時間。他說「我們雖然是生意人，但也喜歡交朋友，只要符合我們的利益就會出手幫助」。

他直言流浪市集是託扎瑞爾的福才能經營，並說艾爾托瑞爾和它的人民在契約上屬於扎瑞爾。他也暗示，自己能為重要客人轉介「實現任何願望」的交易。加格斯說馬哈迪的真身是**羅剎**，但沒有證實。

- [酒館魅魔好難纏](../episodes/2025-11-26.md)：談起耶諾古與扎瑞爾，暗示能轉介願望交易；賣給隊伍兩隻太空倉鼠。
