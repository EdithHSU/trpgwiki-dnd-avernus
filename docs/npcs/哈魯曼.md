# 哈魯曼

!!! info ""
    騎著夢魘的魔鬼騎士（奈祖貢），[哈魯曼之丘](../places/哈魯曼之丘.md)就是以他命名。和[詹德](詹德.md)一樣，曾是扎瑞爾的地獄騎士。

## 身分

哈魯曼全身黑甲，騎著鬃毛與身體纏繞火焰的夢魘，能從像刀割開空間的裂縫中現身。他舉起長槍時，鐵樹上的靈魂會發出讓人恐懼的哀嚎；他也能讓自己的傷口在瞬間癒合。

他的夢魘是靠「地獄鞍具」強迫服從的，打倒他就能得到一頭順從的夢魘。他的同伴是地獄黃蜂。

[詹德](詹德.md)說，當年從即將關閉的傳送門逃走的是詹德，**哈魯曼沒有逃**。哈魯曼把所有逃兵釘在哈魯曼之丘的路上，稱之為「懦夫之路」。[奧蘭蘇斯](奧蘭蘇斯.md)的日記形容他冷酷無情、毫無同情心，會懲罰任何擋在扎瑞爾路上的人。

- [學長是個超級吸血鬼是否搞錯了甚麼](../episodes/2025-12-2.md)：以心靈感應要隊伍「放下那個男人」；夢魘的翅膀被[蓋比](../characters/蓋比.md)射穿，沒能追上隊伍。
- [滅魔器與獨角獸](../episodes/monkie-2.md)：詹德說當年自己逃了、哈魯曼沒有；哈魯曼把逃兵釘在「懦夫之路」上。
