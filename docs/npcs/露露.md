# 露露

!!! info ""
    會飛的金色小象，天界生物，說天界語。曾是扎瑞爾的坐騎與戰友。

## 身分

露露害羞、不習慣跟很多人說話，似乎活了很久，但以前的事幾乎都忘了。她是[崔希哥](崔希哥.md)和[希爾維亞](希爾維亞.md)在博德之門以東的「王者原野」撿到的。原本跟著希爾維亞，因為跟希爾維亞的小惡魔處不來，才被送到崔希哥的法師塔幫忙。

露露能吹出爆炸般的雷鳴巨響，也能噴出一道錐形的聖光，邪惡的生物會在光芒中蒸發。傳說她能變成巨大的象載著騎士作戰，扎瑞爾當年就是站在她背上作戰，但她還想不起怎麼做。

## 與扎瑞爾的過去

扎瑞爾帶領地獄騎士進攻阿弗納斯時，露露就在她身邊。勝利在望時，一些地獄騎士背叛、撤退並封死了傳送門。扎瑞爾被俘前，吩咐露露把她的劍藏起來。有人幫露露藏了劍，但露露已經不記得那個人是誰，也不記得劍藏在哪裡。

在[至高大廳](../places/至高大廳.md)的地下墓穴，露露看著[維提克](../characters/維提克.md)鼓舞倖存者，想起扎瑞爾過去也曾這樣鼓舞眾人。但後來，她認識的扎瑞爾被一個頂著火焰與復仇光環的魔鬼取代了，還對露露說「這才是我」。露露認為扎瑞爾也許覺得自己被托姆拋棄了，而維提克讓她明白，托姆從來沒有拋棄祂的子民。
