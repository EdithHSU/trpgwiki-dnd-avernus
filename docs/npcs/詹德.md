# 詹德

!!! info ""
    全名詹德・晨星，精靈外表的地獄騎士，也是吸血鬼，信仰晨曦之主洛山達。[露露](露露.md)的舊友、[維提克](../characters/維提克.md)的地獄騎士前輩。曾在扎瑞爾的聖戰中叛逃。

## 身分

詹德很久以前是艾爾托瑞爾人，是被詛咒的不死生物。他加入扎瑞爾的聖戰，是為了打破詛咒、替自己贖罪；但進入阿弗納斯沒多久，他就拋下戰友、經由傳送門回到地表，因為他認為那裡已經不是戰爭，只是單方面的屠殺。之後他侍奉洛山達、拯救更多靈魂來贖罪，死後靈魂仍被判到[哈魯曼之丘](../places/哈魯曼之丘.md)受苦，被釘在鐵樹上，靠蚊蝠餵給他的同伴之血活著。

他對墮落極為克制：拒絕喝同伴的血，說那些血的味道是「羞愧」。

詹德說，地獄騎士這個名號，就是「從地獄逃回來的人」。[地獄騎士之墓](../places/地獄騎士之墓.md)的大門仍然承認他是地獄騎士。他曾經從扎瑞爾身邊逃開一次，這次決定不再逃，陪隊伍走完這趟旅程。
