# 耶諾古

!!! info ""
    惡魔領主，稱號「嗜殺惡獸」。身高 14 尺、渾身戰鬥傷疤的巨大豺狼人，痛恨扎瑞爾與[扎瑞爾之劍](../items/扎瑞爾之劍.md)。

## 身分

耶諾古用剝下來的皮肉裝飾自己，手下是鬣狗與崇拜他的豺狼人。他來自深淵，在阿弗納斯被殺死也會回到深淵復活。他一直想摧毀扎瑞爾之劍，痛恨它就像痛恨扎瑞爾一樣；[露露](露露.md)曾與他交戰。

## 經歷

- [跟錢婆婆交車然後開地獄車車](../episodes/2025-11-15.md)：露露說耶諾古一直想摧毀扎瑞爾之劍，建議盡量避開他。
- [酒館魅魔好難纏](../episodes/2025-11-26.md)：[馬哈迪](馬哈迪.md)說越接近扎瑞爾，越可能遇到耶諾古。
- [九根權杖](../episodes/rec-0045.md)：偽裝成侏儒的怪物原本是他的手下。
- [湧血城寨的聖門](../episodes/rec-0050.md)：他手下的巨型惡魔與「耶諾古之牙」在湧血城寨挖掘。
- [露露的回憶：艾德爾格蘭](../episodes/rec-0051.md)：在露露的回憶中親自登場，衝進聖光、咬中好幾名隊員。
