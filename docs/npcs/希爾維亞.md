# 希爾維亞

!!! info ""
    [燭堡](../places/燭堡.md)的中年提夫林女學者，研究魔鬼。小魔鬼耶洗別是她的魔寵。

## 身分

希爾維亞的研究室是一座窗戶緊閉的圓塔實驗室，地板上畫著巨大的九芒星。她多年前見過至高監督者一面，從那時就懷疑他是個騙子。

## 關係

- [崔希哥](崔希哥.md)：欠她人情的巫師朋友。
- [露露](露露.md)：她和崔希哥一起撿到的天界生物，因為跟耶洗別處不來，被送到崔希哥那裡。

## 經歷

- [半獸人小不點](../episodes/2025-06-28.md)：解開謎盒，揭露至高監督者與扎瑞爾的契約。她送給隊伍阿弗納斯地圖、說出[加格斯之盾](../items/加格斯之盾.md)的來歷，並安排隊伍經由崔希哥前往阿弗納斯。
