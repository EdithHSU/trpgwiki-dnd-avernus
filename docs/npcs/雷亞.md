# 雷亞

!!! info ""
    與隊伍同行的地獄騎士聖騎士，信仰托姆。

## 身分

雷亞以身為地獄騎士為榮。她把扎瑞爾的墮落「引以為戒」：就算是為了正義，也不能迷失自己的信念。她與[維提克](../characters/維提克.md)過去的上司都是祭司[吉迪恩・萊特沃德](吉迪恩・萊特沃德.md)。

## 經歷

- [大兒子裸奔](../episodes/2025-04-26.md)：在[萬瑟姆普宅](../places/萬瑟姆普宅.md)地下與女性頭目的戰鬥中多次身受重傷，靠隊友輪番治療撐過。
- [姆普姆普](../episodes/2025-05-17.md)：戰鬥中一度倒地，被隊友搶救回來。
- [要進入第二章囉](../episodes/2025-06-14.md)：在營火邊講述地獄騎士的由來，收下隊伍找到的托姆聖徽。
- [半獸人小不點](../episodes/2025-06-28.md)：得知至高監督者的契約後崩潰跪地，隨即立誓要奪回艾爾托瑞爾。她一度想處決至高監督者，被[凱侖](../characters/凱侖.md)勸下。
- [歡迎來到埃爾圖迦德](../episodes/2025-07-12.md)：隨隊傳送進入[艾爾托瑞爾](../places/艾爾托瑞爾.md)。

- [燒焦的魅魔倒下，但他還是很帥](../episodes/2025-08-16.md)：以至聖斬重創布雷祖魔，陪維提克回家尋找父母。
- [吾劍承忠誠之誓，必逐長夜之影](../episodes/2025-08-30.md)：接下維提克原本的 +1 巨劍；參與淨化被褻瀆祭壇的祈禱。
- [你做了什麼（1）](../episodes/2025-09-07-1.md)：頂著火焰衝鋒，一劍把燃燒的殭屍劈成兩半。
- [你做了什麼（2）](../episodes/2025-09-07-2.md)：接連砍倒骷髏牛頭人與幽靈。
- [磨人的夸賽魔，看你往哪跑](../episodes/2025-09-14.md)：在傳送門前保護[雷文加德大公](雷文加德大公.md)，砍倒一隻牛頭人；主張不必善待魔鬼的手下。
- [在阿弗納斯行軍然後拿到穢液](../episodes/2025-11-08.md)：決定留守艾爾托瑞爾，與雷文加德大公一起守護至高大廳：「這座城市交給我。」
