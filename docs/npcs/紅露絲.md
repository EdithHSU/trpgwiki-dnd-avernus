# 紅露絲

!!! info ""
    住在[骨脊林](../places/骨脊林.md)的預言家鬼婆，每句話都用精靈語的童謠唱出來。

## 身分

紅露絲穿著骨頭縫製的裙子，脖子掛著嬰兒大小的顱骨項鍊，張嘴時滿口鮮紅。她的小屋裡有熬藥的大鍋，牆上掛滿以靈魂幣標價、用血液釀成的藥水；她也能以靈魂幣為代價替人占卜。森林裡附在樹上的亡魂與她是互相攻擊的世仇。

集名「黃鷺鷥唱歌」沿用錄音檔原本的標題，指的就是她。

## 經歷

- [黃鷺鷥唱歌](../episodes/2026-01.md)：請隊伍幫她看家，自己去洗了幾個世紀以來的第一次澡；回來後告訴隊伍拉爾薩拉需要巨人之血、指出[烏爾德拉克](烏爾德拉克.md)的位置，並為隊伍占卜。
