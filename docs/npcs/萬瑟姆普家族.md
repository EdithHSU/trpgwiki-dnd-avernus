# 萬瑟姆普家族

!!! info ""
    博德之門的貴族家族，與死亡三神教、九獄的勢力勾結。宅邸底下藏著一個邪教據點。

## 概況

家族在貴族圈中人緣不佳，據說「幾乎沒有真心朋友，只有巴結者」。家裡的三個兒子分別出自三段婚姻，家族內部對幾個兒子的評價差距很大，有明顯的偏心與矛盾。

- **大少爺阿姆利克**：負責家族的帳務，借錢給隊伍；後來在宅邸被隊伍制伏，被[奎恩](../characters/奎恩.md)以暗示術弄得當眾裸奔到廣場。
- **瑟斯維爾**：深居簡出、從不出門的公子，透過心靈連結操控小惡魔當作耳目，房裡藏著一個受到嚴密保護的盒子。
- **另一名公子**：在第一次錄音前就被隊伍抓住，交給一位公爵看管，留作證人與籌碼。

家族的宅邸見[萬瑟姆普宅](../places/萬瑟姆普宅.md)。
