# 哈金娜

!!! info ""
    帶著一對雙胞胎兒子的女遊俠，背著長弓與劍。在墜入地獄的[艾爾托瑞爾](../places/艾爾托瑞爾.md)被隊伍救下。

## 身分

城市墜落的那天，哈金娜帶著兩個孩子躲進酒館地下室，吃完存糧才冒險出來找物資，結果被鬚魔追殺。一對雙胞胎從小信仰托姆。

## 經歷

- [第一屆美鬚大賽](../episodes/2025-07-26.md)：被隊伍從鬚魔手中救下，提供藏身處與情報，並把銀箭分給[蓋比](../characters/蓋比.md)；隊伍決定護送母子三人前往[至高大廳](../places/至高大廳.md)。
- [燒焦的魅魔倒下，但他還是很帥](../episodes/2025-08-16.md)：又分給蓋比十支銀箭；隊伍請救出的三名盾矮人一起照顧母子三人。
