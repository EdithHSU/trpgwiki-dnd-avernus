# 月色

!!! info ""
    曾被[拉爾沙拉](拉爾沙拉.md)囚禁的獨角獸，跟著隊伍同行了一段時間，之後隨[烏爾德拉克](烏爾德拉克.md)離開阿弗納斯。隊伍稱牠為「月色」（名字一度在月華、月色、彩華之間未定）。

## 身分

月色原本是[扎瑞爾](扎瑞爾.md)的夥伴，隨扎瑞爾的大軍攻打貝爾，後來被扎瑞爾困在「滅魔器」的光球裡，像捕蚊燈一樣不停地消滅邪魔。隊伍打碎裝置救出牠，月色為了感謝治療牠的[凱侖](../characters/凱侖.md)，讓凱侖恢復了善良。

只要月色在身邊，隊伍就不會受到阿弗納斯的腐化。牠不推薦與魔鬼交易，但不干涉隊伍的決定；平常只想旁觀，情況危急時會出手救人。

## 經歷

- [滅魔器與獨角獸](../episodes/monkie-2.md)：被隊伍救出，讓凱侖恢復善良；說出自己原是扎瑞爾的夥伴，也看出加格斯之盾如今是魔鬼的臉。
- [黃鷺鷥唱歌](../episodes/2026-01.md)：在看家的戰鬥中，用角救起倒地的凱侖與[奎恩](../characters/奎恩.md)。
- [殘忍的阿克漢](../episodes/rec-0038.md)：阿克漢的手下一看到牠就想拿牠交易；隊伍沒有把牠交出去，牠很感動。
- [苦痛之息的審判](../episodes/rec-0039.md)：流淚祝福隊伍，補滿所有人的生命值、給了大家最後一次改變陣營的機會，然後跟著[烏爾德拉克](烏爾德拉克.md)離開。
