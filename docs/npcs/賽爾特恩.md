# 賽爾特恩

!!! info ""
    在[艾爾托瑞爾](../places/艾爾托瑞爾.md)出生長大的德魯伊，信仰西凡納斯，陣營中立善良。

## 身分

城市墜落時，賽爾特恩逃到[至高大廳](../places/至高大廳.md)，想和魔鬼戰鬥，被擊倒後只好裝死。他很沮喪地說，在這個靈魂不斷下墜的地方，他與自然的聯繫越來越弱，法術也快失效了。

## 經歷

- [吾劍承忠誠之誓，必逐長夜之影](../episodes/2025-08-30.md)：重傷倒地時被隊伍救下，證實[雷文加德大公](雷文加德大公.md)是在至高大廳引開魔鬼後才出去的。加格斯慫恿[凱侖](../characters/凱侖.md)拉攏他，凱侖因此對他保持戒心。他先到地下墓穴休養。
