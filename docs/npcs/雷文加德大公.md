# 雷文加德大公

!!! info ""
    博德之門的大公。城市墜落後帶著騎士在[至高大廳](../places/至高大廳.md)抵抗魔鬼，前往[大墓地](../places/大墓地.md)後失去消息。

## 身分

大公帶著博德之門與艾爾托瑞爾的騎士，前往不斷湧出不死生物的大墓地。隊伍找到他時，他戴著[托姆之盔](../items/托姆之盔.md)倒在被深淵汙染的水池中，口中交替說著天界語的禱詞與深淵語的詛咒，神聖與惡魔的力量在他的腦中互相抗衡。

## 經歷

- [第一屆美鬚大賽](../episodes/2025-07-26.md)：[哈吉娜](哈吉娜.md)聽說博德之門的大公爵來到了艾爾托瑞爾。
- [吾劍承忠誠之誓，必逐長夜之影](../episodes/2025-08-30.md)：[弗莉亞](弗莉亞.md)說大公前往大墓地後就沒有回來。
- [磨人的夸賽魔，看你往哪跑](../episodes/2025-09-14.md)：在深淵傳送門前的水池裡被找到。隊伍決定不拔下他頭上的頭盔，把他帶回至高大廳舉行儀式。
- [思考魔生的阿弗](../episodes/2025-10-25.md)：在至高大廳的儀式後醒來，說出幻象中女騎士與小象的景象。
- [在阿弗納斯行軍然後拿到穢液](../episodes/2025-11-08.md)：請隊伍出發前幫忙清除至高大廳裡的魔鬼，戰後為隊伍送行。
