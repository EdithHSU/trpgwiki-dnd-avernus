# 弗莉亞

!!! info ""
    在[至高大廳](../places/至高大廳.md)地下墓穴照顧百餘名倖存者的女祭司。

## 身分

弗莉亞頭髮灰白糾結、神情憔悴，一手抱著皮革書，一手拄著隨時會斷的拐杖。至高大廳的其他大祭司與神職人員都已經死了，她獨自照顧從地面撤下來、幾乎沒有戰鬥能力的倖存者。她也會解除詛咒的儀式。

## 經歷

- [吾劍承忠誠之誓，必逐長夜之影](../episodes/2025-08-30.md)：告訴隊伍[雷文加德大公](雷文加德大公.md)前往[大墓地](../places/大墓地.md)後就沒有回來；收下隊伍帶來的五桶水，並畫了墓穴的地圖。
- [磨人的夸賽魔，看你往哪跑](../episodes/2025-09-14.md)：得知大公被托姆之盔與惡魔的力量困住，說明要淨化至高大廳樓上的托姆祭壇才能舉行儀式，請隊伍把大公帶回來。
- [思考魔生的阿弗](../episodes/2025-10-25.md)：主導淨化托姆祭壇的儀式，以無名屠龍者的聖劍為象徵，取下大公的托姆之盔。
