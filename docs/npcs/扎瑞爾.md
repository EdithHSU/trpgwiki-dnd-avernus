# 扎瑞爾

!!! info ""
    阿弗納斯之主。原本是天使，曾率領艾爾托瑞爾的騎士攻入阿弗納斯，戰敗後墮落成魔鬼。至高監督者把艾爾托瑞爾賣給了她。

## 從天使到魔鬼

一個多世紀前，魔鬼肆虐艾爾托瑞爾，統治者向眾神祈求，天使扎瑞爾隨即降臨，帶領數千名騎士穿越傳送門攻入阿弗納斯。她騎在[露露](露露.md)的背上作戰，副將是最忠誠的地獄騎士**耶爾**。勝利在望時，一些地獄騎士背叛、撤退並封死了傳送門，扎瑞爾最終戰敗。被俘之前，她吩咐露露把她的劍藏起來。

露露記得扎瑞爾最後對她說的話：她頂著火焰與復仇的光環，比起天使更像魔鬼，說「**這才是我。那些惡魔死時驚恐地喊著我的名字，這才是真正的我。**」

更早以前，扎瑞爾曾受洛山達之命，守護飽受豺狼人侵擾的小鎮[艾德爾格蘭](../places/艾德爾格蘭.md)，鎮民為她立了一座雕像。她與耶諾古對抗，是因為耶諾古殺了她立誓保護的人；來到阿弗納斯後，邪惡太過強大，一名魔鬼承諾派出地獄軍團助她終結血戰，條件是向阿斯莫蒂斯效忠。她答應了，成為魔鬼大公。

## 現在

扎瑞爾統治著阿弗納斯，流浪市集也仰賴她才能經營。依[至高監督者](至高監督者.md)簽下的契約，艾爾托瑞爾與立誓守護它的人民都屬於她。她的敵人包括九獄第一層的前任大公[貝爾](貝爾.md)、惡魔領主[耶諾古](耶諾古.md)，以及提亞瑪特的信徒[殘忍的阿克漢](殘忍的阿克漢.md)。

露露相信，扎瑞爾當年把她送離阿弗納斯，是扎瑞爾心中殘存的善良；而[扎瑞爾之劍](../items/扎瑞爾之劍.md)保留了她的善良力量，能喚起她的良知。
