# 崔希哥

!!! info ""
    以水獺形態生活的古怪巫師，穿著小號的紅色法袍。

## 身分

崔希哥曾向[希爾維亞](希爾維亞.md)借過法術書，因此欠她人情。他有能力變成水獺，也喜歡這個樣子。[露露](露露.md)平時住在他的塔裡幫忙。

## 法師塔

一座浮在海上空中、沒有門窗的高塔，只能從塔頂的鋸齒狀洞口進出。塔內物品被施加了永燃之焰用來照明，房間堆滿煉金器材與雜物。

## 經歷

- [歡迎來到埃爾圖迦德](../episodes/2025-07-12.md)：以音叉施法，把隊伍單程傳送進艾爾托瑞爾，自己隨即緊張地消失。魔法貓嘴嘴暫時留在他的塔裡。
